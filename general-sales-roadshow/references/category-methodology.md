# 品类侧重点 · 通用推导方法论（skill 核心）

> 本文件是「通用销售路演 skill」区别于垂直版的关键。它解决一个问题：**当用户给出的品类不在预置清单里时，如何不靠穷举、而靠方法论稳定推导出该品类的路演侧重点。**
>
> 内置的 15 品类（见 `category-playbook.md`）是**已沉淀的默认知识底座**，本方法论是其背后的「生成逻辑」——你既可以直接用现成清单，也可以用本方法为新品类当场推导。

---

## 一、两个底层坐标系

任何 B2B 采购，买家的关注点都可以落在两个坐标系上。推导品类侧重点，就是把一个品类同时投影到这两个坐标系，取交集。

### 坐标系 A：价值链位置（决定你卖的是"什么形态的东西"）

| 位置 | 典型品类样例 | 路演要证明的本质 |
|------|------------|----------------|
| 上游原料/耗材 | 原料、化工、包材、零部件 | 稳定、合规、可追溯、适配 |
| 硬件/设备/工具 | 机械设备、仪器、产线 | 产能、可靠、ROI、运维 |
| 生产/制造服务 | OEM/ODM、代工、CRO/CDMO | 资质、排产、质控、保密 |
| 终端产品(供货) | 品牌货、成品、标品 | 政策、动销、履约、周转 |
| 软件/数字/服务 | SaaS、咨询、运维、解决方案 | 效果、实施、续费、风险 |

### 坐标系 B：采购决策核心因子（决定买家"凭什么签你"）

任何品类都逃不出这 8 个因子，只是权重不同：

1. **成本 / 降本**（价格梯度、TCO、账期）
2. **质量 / 稳定**（批次一致、不良率、质控体系）
3. **交期 / 连续性**（lead time、安全库存、履约保障）
4. **合规 / 资质**（许可、认证、审计可过）
5. **技术 / 适配**（参数、兼容、配方/接口、打样）
6. **风险 / 安全**（食安/质量/供应中断/数据/法律）
7. **服务 / 运维**（售后、备件、响应、培训）
8. **商业 / 增长**（渠道、动销、ROI、长期价值）

## 二、推导四步法（对任意品类通用）

拿到一个品类（或用户一段业务描述），按以下四步推导其路演侧重点：

**Step 1 — 定位价值链坐标**
> 问：这个品类在上表里属于哪个位置？它决定"路演要证明的本质"。

**Step 2 — 排布决策因子权重**
> 问：对该品类的买家，8 个因子里哪 3–5 个权重最高？用"高/中/低"标注。
> 参考：原料→合规/稳定/交期权重高；设备→产能/ROI/运维高；代工→资质/排产/保密高；软件→效果/实施/续费高。

**Step 3 — 映射成具体侧重点清单**
> 把高权重因子翻译成 6–10 条该品类**听感上专属**的业务侧重点（用买家行话，不用通用词）。
> 例：因子"合规/资质"映射到"原料"= 溯源+批次稳定性+质检标准；映射到"软件"= 等保+数据合规+审计日志。

**Step 4 — 锁定角色与风险口径**
> 高权重因子决定哪些参会角色最关心（见 `role-concerns.md`），以及风险预警该防什么（交期断供？合规翻车？IP 泄露？）。

**输出格式（直接进成稿）：**
```
品类：[用户给出]
价值链坐标：[A 类]
高权重决策因子：[列出 3–5 个]
→ 路演侧重点：①…②…③…（6–10 条，买家行话）
→ 主攻角色：[角色]
→ 首要风险：[风险类型]
```

## 三、12 个硬性问答主题的「品类映射」

规则②要求应答库必须覆盖 12 个主题。其中大部分是跨品类通用的，**只有"食品安全风险"在通用版里要按品类映射**：

| 通用主题 | 非食安品类的映射口径 |
|---------|-------------------|
| 食品安全风险 | → **产品安全/质量/合规风险**，按品类命中核心风险域（全品类映射表见下） |
| 资质合规 | 通用，但证件类型随品类变（食品=SC/蓝帽子；设备=CE/特种设备；软件=等保/ISO27001；医药=注册证/GMP；农资=登记证；ToG=政采资质） |
| 最小起订量 | 通用（原料/包材/代工称 MOQ；软件称起订席位/最低消费） |
| 售后/运维 | 通用（设备=运维；软件=技术支持/SLA；代工=客诉处理；ToG=验收运维） |
| 其余 8 项 | 价格、交期、样品打样、供货稳定性、竞品对比、知识产权保密、账期、降本量化测算 —— **全品类通用**，直接覆盖。 |

**「食品安全风险」主题的全品类映射表**（权威口径见 `qa-bank.md` §10.1，含每类应答框架与典型尖锐提问；下表为速查版）：

| 品类 | 映射后的风险域 |
|------|--------------|
| 食品/功能食品/食用原料/终端食品 | 食品安全（污染/掺假/标签/召回） |
| 化妆品 | 成分安全/备案合规/不良反应 |
| 工业/化工原料、包材 | 杂质/批次漂移/材质安全/环保 |
| B 端代工（OEM/ODM） | 质量责任划分/配方/IP 保密 |
| SaaS/软件 | 数据安全/等保/隐私/可用性 |
| 工业设备/机械 | 运行安全/安规认证/停机故障 |
| 医药器械 | 注册证/GxP/上市后监管 |
| 建材 | 国标达标/环保/防火等级 |
| 农资 | 登记证/农残/抽检合格 |
| 政务信息化/ToG 方案 | 政采合规/信创/数据安全/验收审计 |
| 化工原料/新材料 | 指标稳定性/批次漂移/危化品安全/环保合规（并入"工业/化工原料、包材"行统一处理） |
| 新能源（光伏/储能/锂电） | 衰减与质保承诺/认证合规（TÜV/UL/CQC）/并网与安全/长期运行可靠 |

> 实操：对食安类品类保留"食品安全风险"原词；对其它品类在成稿应答库标题写为"食品安全风险（映射：产品安全/质量风险）"，正文按上表对应风险域展开——既满足 12 主题全覆盖，又不穿帮。拿不准品类时先反问客户最担心哪类风险（合规资质/质量稳定/安全责任），再命中对应域。

## 四、内置 15 品类的「方法论还原」（证明方法可用，并作示例）

以下把 `category-playbook.md` 的 15 个清单，用本方法论还原一遍，方便你理解"清单从哪来"；遇到新品类，照此现场推导即可。

| 品类 | 价值链坐标 | 高权重因子 | 侧重点（来自 playbook） |
|------|-----------|-----------|----------------------|
| 原料 | 上游原料 | 合规/稳定/交期 | 溯源、资质合规、批次稳定、供货保障、交期、质检、价格梯度、备货、配方适配 |
| 机械设备 | 硬件设备 | 产能/ROI/运维 | 产能、故障率、运维售后、交付周期、能耗、产线适配、质保、备件、改造兼容、ROI |
| 化妆品 | 终端/配方 | 质量/合规/技术 | 配方安全、备案合规、肤感、原料来源、打样周期、质控 |
| 功能食品 | 终端/食安 | 合规/质量/风险 | 婴标/保健食品资质、配方合规、检测报告、生产资质、批次、标签合规、食安风险 |
| 包装材料 | 上游耗材 | 成本/交期/质量 | 材质安全、起订量、打样、印刷工艺、交期、损耗、仓储、版本迭代、成本优化 |
| B端代工 | 制造服务 | 资质/排产/保密 | 产能、车间资质、排单、配方开发、打样、质控、IP保密、MOQ |
| 终端产品B端 | 终端供货 | 商业/履约/周转 | 渠道政策、供货价、动销、退换货、库存周转、品控、履约交付 |
| SaaS/软件 | 软件/数字服务 | 效果/实施/续费/合规 | 实施周期、并发稳定、对接、数据合规、SLA、续费增购、权限审计 |
| 工业设备/制造 | 硬件设备 | 产能/ROI/运维/安全 | 节拍产能、MTBF、运维响应、交付安装、能耗TCO、改造兼容、备件质保 |
| 医药器械 | 制造服务/受监管硬件 | 合规/质量/风险 | 注册证(NMPA)、生产许可与GMP体系、临床/验证证据、UDI追溯、带量采购/挂网、两票制、质量体系、合规营销 |
| 建材 | 上游耗材/工程材料 | 合规/成本/风险 | 国标达标、防火/环保认证、型式检验与送检配合、工程业绩、交付周期、质保与责任险、账期、施工配合、投标资质 |
| 农资 | 上游耗材（农业投入品） | 合规/风险/服务 | 登记证/生产许可、肥效药效数据、作物适配、抽检合格、储运安全、旺季保供、账期与赊销、渠道窜货管控 |
| 化工原料/新材料 | 上游原料 | 合规/稳定/风险 | 危化品资质/MSDS、纯度与批次一致性、安环合规、供应连续性、技术指标、账期授信、仓储物流资质 |
| 新能源（光伏/储能/锂电） | 硬件设备（长周期资产） | 合规/质量/商业 | 并网/认证标准(TÜV/UL/CQC)、衰减质保承诺、度电成本LCOE、长期运维、融资租赁、安全消防、项目全周期 |
| 政务信息化/ToG | 软件/数字服务（政采） | 合规/风险/服务 | 政采合规、资质/业绩门槛、预算与财政口径、信创适配、里程碑验收、审计留痕、回款周期 |

**新品类推导示例（演示方法）：**
- 用户品类 = "工业传感器（硬件/零部件）"
- Step1 价值链坐标：上游原料/零部件（偏硬件）
- Step2 高权重因子：质量稳定、交期、技术适配、成本
- Step3 侧重点 → 精度/一致性、批次校准、供货周期、接口兼容性、认证(CE/ROHS)、价格梯度、备货、样品测试、质保
- Step4 主攻角色：研发/技术 + 采购；首要风险：交期断供/批次漂移

## 五、什么时候用清单，什么时候用推导

- 用户品类 ∈ {原料,机械设备,化妆品,功能食品,包装材料,B端代工,终端产品B端,SaaS/软件,工业设备/制造,医药器械,建材,农资,化工原料/新材料,新能源,政务信息化/ToG}（共 15 类）→ **直接用 `category-playbook.md` 清单**（已沉淀最优口径）。
- 用户品类 ∉ 上述 15 类（如服装、工业传感器、食品机械等）→ **用本方法论 Step1–4 现场推导**，产出该品类专属侧重点，再进成稿。
- 用户只给一段业务描述、没点名品类 → 先从句中识别价值链坐标，再推导；识别不出则走缺数据流程（见 SKILL.md Step6）。

# 参会角色关注点拆解手册（role-concerns · 六维画像版）

> 路演到场什么人，内容口径就往哪偏。角色画像为**六维画像**：决策关注 / 利益诉求 / 典型质疑 / 价值话术 / 验收标准 / 红线，并含**法务/合规负责人**与**使用部门/业务负责人**两类角色，技术、法务、财务三个角色深度展开。
>
> 正式成稿的【参会角色关注点拆解】按实际到场角色摘录并展开：每类角色写清"他关心什么 + 本场怎么回应 + 他的验收标准和红线"，避免只泛泛说"关注成本"。
>
> **六维口径速记**：关注=他盯着什么目标；诉求=他要什么好处；质疑=他会怎么刁难；话术=怎么回应；验收=他凭什么认可；红线=什么情况他一票否决。

---

## 1. 采购总监 / 供应链负责人
- **决策关注**：综合降本收益、供应风险可控、合规可审计、交期稳定、整体 ROI；换供应商的转换成本与断供风险。
- **利益诉求**：在老板面前展示降本业绩与供应链韧性；不希望因为换供而背锅。
- **典型质疑**：
  - "你们比我现在供应商贵 5%，凭什么换？"
  - "万一断供，我的产线停一天损失谁担？"
  - "审计来查，你们资质能随时出吗？"
- **价值话术**：用"综合降本 + 风险可控"收口——给可量化的 ROI（含隐性成本对比）、备选供应商/备产线兜底、换料测试免费、过渡期双供方案。
- **验收标准**：降本测算表能经得住老板和财务复核；风险预案白纸黑字；资质文件即时可调档。
- **红线**：断供无兜底、数据拿不出来、空口承诺无证据、报价有隐性坑（运费/损耗/备件另算）。

## 2. 技术负责人 / CTO / 研发经理
- **决策关注**：技术可行性（参数/配方/兼容性/接口）、性能指标是否达标、与现有技术栈/产线融合、长期可维护性、技术风险与兜底。
- **利益诉求**：在技术决策中建立权威；避免"我拍板的技术方案翻车"；希望拿到能直接上会/写进技术方案的硬数据。
- **典型质疑**：
  - "这个原料/接口和我们的体系相容吗？有相容性数据吗？"
  - "性能指标第三方测过吗？能达到你们宣称的数值吗？"
  - "万一不稳定，怎么兜底？有没有对照实验/压测数据？"
  - "你们的架构/配方会不会限制我们后续扩展？"
- **价值话术**：给硬参数、给检测/压测/对照数据、给样品/POC、给技术路线图；少谈商务多谈技术可行性；主动给出"如果技术不达标我们负责什么"的兜底条款。
- **验收标准**：拿到可复现的测试数据与样品；技术方案能过内部技术评审；对兼容性/扩展性有明确结论而非"应该没问题"。
- **红线**：参数造假或夸大、无数据支撑的承诺、"这个我们后面再测"式的回避、隐瞒已知技术缺陷。

## 3. 生产 / 运营负责人
- **决策关注**：产能匹配、交付周期、现场调试、供货连续性、不停线不停供。
- **利益诉求**：生产任务顺利达成，少加班少救火；不愿因新供应商磨合期出乱子。
- **典型质疑**：
  - "新设备/新物料多久能到、谁来调试？"
  - "旺季你能不能保我连续供货？"
  - "和我现有产线/工艺兼容吗，要不要大改？"
- **价值话术**：讲交付节奏与现场支持，承诺不停线不停供；给过渡期排产方案、调试团队驻场时间、旺季备货预案。
- **验收标准**：交付/排产时间表明确且可执行；有磨合期应急预案；现场支持资源已排定。
- **红线**：交付日期含糊、调试人员不到位、旺季断供无预案。

## 4. 财务 / CFO
- **决策关注**：预算匹配、总拥有成本（TCO，含隐性成本）、账期与现金流、投资回收期、税务与合规对财务的影响。
- **利益诉求**：守住现金流与预算红线；避免"看起来便宜、算总账贵"的采购翻车；在预算委员会面前有据可依。
- **典型质疑**：
  - "超我预算了吗？全生命周期成本算过没有？"
  - "账期能给到 60 天吗，门槛和利息/贴息成本是什么？"
  - "隐性成本（运费/损耗/备件/实施/维护）算进去多少？"
  - "采购/付款走什么流程？会不会影响我们现金流周转？"
- **价值话术**：把总价拆成单位成本与回收周期（如"单吨成本降 X%、12 个月回收"）；账期政策、门槛、贴现成本说清；提供含隐性成本的全生命周期测算表。
- **验收标准**：拿到可复核的 TCO/ROI 测算口径；账期条款无隐藏费用；付款流程与发票资质清晰。
- **红线**：只报裸价隐瞒隐性成本、账期承诺无书面、现金流测算经不起推敲、发票/合同流程不合规。

## 5. 法务 / 合规负责人
- **决策关注**：合同条款风险（责任划分、保密、违约责任）、资质与许可合规、知识产权归属、数据合规、监管红线（食安/医疗/危化/政采等）。
- **利益诉求**：把合同风险和合规风险挡在签章之前；不希望留下背锅的漏洞条款；在合规审查中体现专业把关。
- **典型质疑**：
  - "责任划分怎么写的？出质量问题谁担责、赔多少？"
  - "保密协议能覆盖我们哪些信息？违约责任怎么约定？"
  - "你们的资质/认证真实有效吗？会不会影响我们合规备案？"
  - "数据归属、本地化存储怎么约定？"
- **价值话术**：主动给出合同范本与关键条款摘要、责任矩阵、合规资质清单与有效期、NDA 模板；强调"文件齐、条款清、留痕全"。
- **验收标准**：关键风险点（责任/保密/违约/资质/数据）在合同中有明确条款；资质文件可核验；不留模糊地带。
- **红线**：拒绝提供合同范本、责任条款含糊或推诿、资质过期或证照不符、试图用口头承诺替代书面条款。

## 6. 执行采购 / 供应链专员
- **决策关注**：流程便捷度、对账与开票、样品获取、沟通响应效率、下单系统兼容。
- **利益诉求**：日常工作省事、不被催单、对账不出错；找"好配合、响应快"的供应商减少自己工作量。
- **典型质疑**：
  - "样品怎么申请，几天能到？"
  - "对账和开票谁对接，响应快不快？"
  - "下单流程复杂吗，能不能走系统？"
- **价值话术**：强调对接人固定、响应时效（如 2h 回单）、对账清晰、样品易拿、支持系统下单。
- **验收标准**：对接流程清晰、首单体验顺畅、对账无错漏。
- **红线**：响应拖沓、对接人常换、对账反复出错。

## 7. 企业高管 / CEO（决策层）
- **决策关注**：业务增长、战略协同、风险规避、长期合作价值、对公司品牌的加分项。
- **利益诉求**：谈成一个能写进年报/董事会汇报的"战略合作"；不希望踩合规或声誉雷。
- **典型质疑**：
  - "合作能帮我业务增长什么？"
  - "政策/合规风险你们怎么兜底？"
  - "长期绑定的价值在哪，还是换汤不换药？"
- **价值话术**：拔高到"供应链韧性 + 增长协同"，讲长期价值而非单笔价格；给战略级合作框架（联合创新/优先产能/年度框架）。
- **验收标准**：合作方案能支撑战略叙事（增长/安全/降本其一）；风险有兜底；有可落地的长期机制。
- **红线**：只谈价格没战略、合规风险高、承诺无法兑现。

## 8. 使用部门 / 业务负责人（SaaS/设备/终端产品场景尤其关键）
- **决策关注**：产品/方案好不好用、能不能解决一线实际问题、上线/落地后的培训与支持、对业务指标的帮助。
- **利益诉求**：让一线团队真的用起来、出效果；不想被迫用"不好用的系统/设备"背绩效锅。
- **典型质疑**：
  - "这产品我们一线实际怎么用？上手成本高不高？"
  - "上线/安装后谁来培训、谁支持？出了问题找谁？"
  - "能不能先小范围试点看效果，再决定推广？"
- **价值话术**：给试点方案、培训与支持承诺、一线使用案例、落地时间表；强调"用起来顺畅、有人管到底"。
- **验收标准**：试点/小范围验证效果可见；培训与支持资源到位；一线反馈良好。
- **红线**：功能炫但不好用、无培训无支持、拒绝试点强推全量。

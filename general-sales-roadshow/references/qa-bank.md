# 高频&尖锐问题应答库框架（qa-bank）

> 硬性要求：正式成稿的【高频&尖锐问题应答库】必须覆盖以下 12 个主题，缺一不可。每个主题给"为什么被问 + 应答框架 + 常见陷阱"。正式成稿时用真实数据填充，并把框架转成可直接念的口语应答。

---

## 1. 价格
- **为什么被问**：采购第一刀永远是价。
- **应答框架**：价格梯度（按量分档）+ 综合成本（含损耗/运费/隐性成本）+ 与竞品价值差，不陷入单纯比单价。
- **陷阱**：只报一口价被压价；没算隐性成本显得"便宜但坑"。

## 2. 交期
- **为什么被问**：产线等米下锅，断料=停线。
- **应答框架**：标准交期 + 加急方案/备货机制 + 旺季预案，给确定性。
- **陷阱**：拍胸脯"随时有货"却无备货证据，一旦爽约信用破产。

## 3. 最小起订量（MOQ）
- **为什么被问**：小批量试错 vs 大批量压库存的博弈。
- **应答框架**：标准 MOQ + 柔性起订（试单政策）+ 阶梯价对应起订量。
- **陷阱**：MOQ 卡死试单，把客户挡在门外。

## 4. 资质合规
- **为什么被问**：审计、备案、食安红线，缺资质直接出局。
- **应答框架**：资质清单逐项对应客户需求（SC/ISO/备案/蓝帽子等）+ 可随时调档 + 合规更新机制。
- **陷阱**：资质过期或张冠李戴；答"应该有"而非"确实有"。

## 5. 样品打样
- **为什么被问**：研发要实测才敢下单。
- **应答框架**：打样周期 + 费用政策（免费/抵扣）+ 打样到量产的转化路径。
- **陷阱**：打样慢、收费不清，研发失去耐心转投竞品。

## 6. 供货稳定性
- **为什么被问**：怕断供、怕批次漂移。
- **应答框架**：产能冗余 + 安全库存/备货 + 备选产线 + 批次一致性管控（COA/留样）。
- **陷阱**：只说"我们很大"无数据支撑。

## 7. 竞品对比
- **为什么被问**：客户在比价比方案。
- **应答框架**：客观承认竞品优势点 + 差异化壁垒（合规/供货/研发/IP）+ 不贬低对手。
- **陷阱**：贬低竞品显得不专业；回避对比显得心虚。

## 8. 售后 / 运维
- **为什么被问**：设备/代工出问题谁兜底。
- **应答框架**：响应时效（如 24h 到场）+ 质保范围 + 备件供应 + 远程诊断。
- **陷阱**："终身服务"无细则，出事扯皮。

## 9. 知识产权保密（IP）
- **为什么被问**：OEM/ODM 客户怕配方/品牌泄露。
- **应答框架**：NDA + 物理隔离产线 + 权限分级 + 泄密追责条款。
- **陷阱**：只口头承诺无书面隔离机制。

## 10. 产品安全 / 质量 / 合规风险（按品类映射，原名「食品安全风险」）

> **为什么这条主题是"品类映射"的核心**：客户追问"安全风险"时，问的其实是"你最可能在哪翻车"。食安类客户问食安，软件客户问数据安全，医药客户问注册监管——**答错赛道 = 直接暴露你不懂行**。因此必须按品类命中对应风险域，不能只讲"我们很安全"的空话。
>
> **成稿写法**：食安类品类保留「食品安全风险」原词；其它品类在应答库标题写为「食品安全风险（映射：产品安全/质量风险）」以保证 12 主题全覆盖，正文按下方映射表对应风险域展开。

### 10.1 品类 → 核心风险域映射表（全品类覆盖）

| 品类 | 核心风险域（客户最怕的翻车点） | 应答框架（按此展开） | 典型尖锐提问 |
|------|-------------------------------|----------------------|-------------|
| 食品 / 功能食品 / 原料（食用） / 终端食品 | 食品安全：污染、掺假、标签违规、召回 | 全项检测（农残/重金属/微生物）+ 批次追溯 + 留样 + 召回预案 + 零事故记录 + 食安体系认证（HACCP/ISO22000） | "出过召回吗？追溯能做到哪一批？" |
| 化妆品 | 成分安全、备案合规、过敏/不良反应 | 全成分合规（禁用/限用清单）+ 备案凭证 + 功效宣称有依据 + 过敏测试 + 不良反应监控 | "功效宣称有检测报告吗？备案号能给吗？" |
| 原料（工业/化工）/ 包材 | 杂质、批次漂移、材质安全、环保合规 | 全项 COA + 杂质谱 + 批次一致性 + 材质安全（食品级/接触材料合规）+ 环保检测 | "批次之间成分波动多少？有 COA 随货吗？" |
| B 端代工（OEM/ODM） | 质量责任划分、配方/IP、客诉归因 | 质量协议（权责划分）+ 过程抽检 + 留样 + 客诉 8D 处理 + 保密隔离 | "我的批次出问题，责任怎么划分？" |
| SaaS / 软件 | 数据安全、等保合规、隐私、可用性 | 等保测评 + 数据加密/脱敏 + 权限审计日志 + 隐私合规（个保法）+ 容灾与 RTO/RPO + SLA | "过等保了吗？数据存在哪、谁能碰？" |
| 工业设备 / 机械制造 | 运行安全、安规认证、故障停机风险 | 安规认证（CE/3C/ISO）+ 防护设计 + MTBF/故障率 + 停机保障与备件 + 安全培训 | "出了安全事故算谁的？有安规认证吗？" |
| 医药器械 | 注册证、GxP、上市后监管、临床证据 | NMPA 注册证 + GMP/生产许可 + 不良事件上报 + 飞检应对 + 效期管理 | "注册证齐全吗？能通过飞检审计吗？" |
| 建材 | 国标达标、环保、防火等级、质量检测 | 国标（GB）达标报告 + 环保（甲醛/VOC）+ 防火等级 + 型式检验 + 工程备案 | "有型式检验报告吗？防火等级是多少？" |
| 农资（农药/化肥/种子） | 登记证、农残、抽检合格、使用安全 | 登记证（农药登记/肥料登记）+ 农残限量合规 + 抽检合格记录 + 施用安全说明 | "登记证号是什么？抽检合格率多少？" |
| 政务信息化 / ToG 方案 | 政采合规、信创、数据安全、验收审计 | 政采法合规（招投标资质）+ 信创适配认证 + 等保/分级保护 + 数据主权本地化 + 审计留痕 | "过政采合规了吗？能过第三方验收审计吗？" |

### 10.2 包装材料三子类专属高频问题（玻璃 / 塑料 / 金属）

> 包装材料客户问"安全风险"时，实际问的是**具体材质在哪翻车**。按客户实际用的材质命中对应子类提问，答错赛道（如对金属罐讲"迁移检测"、对玻璃讲"可降解"）直接穿帮。以下为各子类最高频的尖锐提问与应答口径。

**① 玻璃（食品级玻璃 / 瓶罐）**

| 客户原话 | 应答口径（口语、可直接念） | 关键证据 |
|---------|---------------------------|---------|
| "玻璃易碎，运输损耗怎么算？" | "我们按运输方案打包，破损率实测控在 X% 以内；约定破损补货条款，损耗算我们的，不让您担风险。" | 跌落/运输破损率实测数据、破损补货条款 |
| "瓶型、丝印、磨砂能做吗？打样多久？" | "瓶型定制、丝印、磨砂工艺我们都做，新品打样 7 天出一版，您上市节点不耽误。" | 瓶型与丝印/磨砂样品、打样周期承诺 |
| "食品级玻璃合规吗？有检测吗？" | "过 GB 4806 食品接触标准，迁移检测报告随时调档，审厂能过。" | GB 4806 食品接触合规证明、迁移检测报告 |
| "批次一致性能保证吗？" | "每批留样 + 外观/尺寸抽检记录，批次间色差、壁厚一致性我们按标准控。" | 批次一致性记录、留样记录 |

**② 塑料（PET / PP / HDPE / 可降解）**

| 客户原话 | 应答口径（口语、可直接念） | 关键证据 |
|---------|---------------------------|---------|
| "材质是 PET 还是 PP？适合装什么？" | "PET、PP、HDPE 按用途给您选型——透明需求用 PET，耐热用 PP，强度/化工用 HDPE，我给到用途对照表。" | PET/PP/HDPE 材质证明与用途对照 |
| "食品接触迁移检测有吗？" | "每批都有食品接触迁移检测（GB 4806），报告随货可查，客户要调档随时给。" | 迁移检测报告（GB 4806/国标） |
| "禁塑令来了你们怎么办？" | "限塑地区我们提前适配过，可降解方案（PLA/PBAT 等）有降解认证，您不用临时换供应商。" | 可降解方案与降解认证、禁塑令/环保政策跟进说明 |
| "克重壁厚能帮我们省成本吗？" | "克重壁厚按装盛物和成本帮您算，既达标又不浪费料，包材成本往下压。" | 克重壁厚规格表、成本优化测算 |

**③ 金属（马口铁 / 铝罐）**

| 客户原话 | 应答口径（口语、可直接念） | 关键证据 |
|---------|---------------------------|---------|
| "罐子密封性怎么样？保质期够吗？" | "马口铁和铝罐密封性都过检测，配合内壁涂层防腐，货架保质期能按您的工艺给到 X 个月。" | 密封性/密封检测报告、保质期验证数据 |
| "内壁涂层安全吗？会不会析出？" | "内壁涂层是食品接触合规的，罐体不析出，长保产品敢用。" | 内壁防腐涂层食品接触合规证明 |
| "能做易拉盖、二维码吗？" | "易拉盖、二维码都能做——开盖体验 + 一罐一码追溯/营销，一瓶多卖一层价值。" | 易拉盖/二维码（追溯/营销）方案样例 |
| "罐型能定制吗？交期多久？" | "罐型可定制，常规交期 X 天，起订量按罐型给阶梯价。" | 罐型定制能力说明、交期与起订量 |

### 10.3 三类通用兜底（映射表未覆盖的新品类时用）

- **通用应答骨架**：风险域识别（"这个品类客户最怕什么翻车"）+ 风险清单逐项给证据（检测/认证/追溯/预案）+ 责任承诺与兜底条款 + 零事故/零违规记录（有则说，无则标【需补】）。
- **追问定域**：拿不准客户最怕什么时，先反问一句再答——"您最关心的是合规资质、质量稳定还是安全责任？"避免答错赛道。
- **红线**：绝不把食安框架硬套到软件/设备上（如对软件讲"全项检测+留样"会穿帮）；也绝不回避风险只讲"我们很安全"。

## 11. 账期
- **为什么被问**：财务要现金流。
- **应答框架**：账期政策（如 30/60 天）+ 门槛（首单现结、信用额度）+ 量大可谈。
- **陷阱**：无门槛放账期增大坏账；或一刀切现结丢掉大客户。

## 12. 降本量化测算
- **为什么被问**：采购总监/财务要算账。
- **应答框架**：单位成本对比 + 损耗/能耗/人工节省 + 回收周期（ROI）+ 年综合降本额（% 或金额）。
- **陷阱**：只给模糊"能省不少"，无测算口径，决策层不买账。

# 通用销售路演 Skill

版本：v1.7.2 | 作者：liucaiwei

## 这是什么

一个「豆包工作」Skill：输入路演需求，10分钟生成8大模块完整输出——口语化演讲稿、PPT大纲、高频问题应答库、竞品雷达图、.pptx直出，附29项合规自动校验。换行业不用重写，改个品类参数就行。

## 核心能力

| 能力 | 说明 |
|---|---|
| 8大模块一键生成 | 核心目标、客户细分、参会角色、演讲稿、PPT大纲、Q&A库、风险预警、跟进清单 |
| 12个高频主题全覆盖 | 价格、交期、MOQ、资质合规、样品、供货稳定性、竞品对比、售后、IP保密、食品安全、账期、降本量化 |
| PPT大纲+竞品雷达图 | SVG矢量雷达图，.pptx直出11页完整PPT |
| 29项合规自动校验 | 无占位符、无编造、竞品对比定量 |

## 8大模块

1. 路演核心目标
2. 客户细分 & 品类定位
3. 参会角色关注点
4. 口语化完整演讲稿
5. PPT大纲
6. 高频 & 尖锐问题应答库
7. 风险预警 & 临场应对
8. 会后跟进动作清单

## 质量保证

29/29 项回归测试全部通过，含受限环境临时目录回退，逻辑闭环。

运行测试：
```bash
bash scripts/test.sh
```

## 安装与使用

1. 下载本目录
2. 在豆包工作中导入 Skill
3. 输入路演需求，一键生成

## 运行环境

- Node.js v18+ 或 Deno
- 依赖：pptxgenjs（已内置在 scripts/vendor/）

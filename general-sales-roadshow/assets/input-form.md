# 路演信息录入表（结构化 · 跨平台可移植）

> 用途：把客户与方案信息按字段填好，交给路演顾问生成八模块成稿。
> 格式说明：① **Markdown 表单**——可原样粘贴进飞书/Notion/Obsidian/任意 Markdown 编辑器，或直接手填；② **YAML 数据块**——供程序/脚本解析，与表单一一对应。两种任选，不必都填。
> 带 `*` 为 7 项必填（缺任意一项顾问会列出缺失项，不编造）。

---

## A. Markdown 表单（复制填写）

```markdown
# 路演客户信息卡

## *1. 客户所属细分品类（内置15类任选，或自定义任意品类）
- 内置15类：原料 / 机械设备 / 化妆品 / 功能食品 / 包装材料 / B端代工(OEM/ODM) / 终端产品B端供货 / SaaS软件 / 工业设备制造 / 医药器械 / 建材 / 农资 / 化工原料·新材料 / 新能源 / ToG政务专项
- 自定义新品类：直接写品类名即可（如工业传感器、服装、食品机械…），顾问会用通用推导方法论现场产出侧重点
→ 填：

## *2. 客户行业 / 企业背景
（行业、规模、业务模式、上下游位置）
→ 填：

## *3. 当前采购痛点（原话最好）
→ 填：

## *4. 本次路演目标
拿样 / 试单 / 进合格供应商库 / 年度框架 / 战略合作
→ 填：

## *5. 参会人员岗位
（例：采购总监1 + 研发经理1 + 生产主管1）
→ 填：

## *6. 我方产品 / 方案（含核心卖点原材料）
（产品/服务描述、特性、参数、优势点罗列均可；卖点话术由顾问草稿化）
→ 填：

## *7. 客户预算
→ 填：

## 8. 路演设置（非必填，有则填）
- 模式：正式对外路演 / 采购演练模式
- 时长：默认15分钟（可写 10/20/30 等）
→ 填：
```

---

## B. YAML 数据块（程序/脚本解析用）

```yaml
roadshow_input:
  category: ""            # 内置15类任选，或自定义任意品类（如工业传感器/服装/食品机械）
  client_background: ""   # 客户行业/企业背景
  pain_points: ""         # 当前采购痛点
  goal: ""                # 路演目标
  attendees: ""           # 参会人员岗位
  our_solution: ""        # 我方产品/方案 + 核心卖点原材料
  budget: ""              # 客户预算
  settings:
    mode: "正式对外路演"   # 或 采购演练模式
    duration_min: 15       # 整数分钟
```

> 填写后把整段（A 或 B）贴给顾问即可。若只想快速开始，也支持**直接粘贴一段杂乱介绍**，顾问会自动抽取填入上述字段、缺的标【需补】。

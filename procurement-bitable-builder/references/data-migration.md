## 2. 迁移前准备
### 2.1 数据盘点清单
在开始迁移前，先盘点现有数据：
| 序号 | 检查项 | 说明 | 结果（示例） |
|------|--------|------|-------------|
| 1 | 现有 Excel 文件数量 | 列出所有相关文件 | 5 个文件 |
| 2 | 每个文件的记录数 | 数据量评估 | 供应商表 38 条、订单表 1200 条 |
| 3 | 数据时间范围 | 需要迁移的历史数据范围 | 2024-01 至 2026-07 |
| 4 | 数据质量评估 | 格式混乱程度 | 日期格式不统一、状态值不标准 |
| 5 | 数据责任人 | 每份数据的确认人 | 供应商表-张三、订单表-李四 |
| 6 | 敏感数据识别 | 银行账号、合同金额等 | 供应商银行账号需脱敏处理 |
### 2.2 环境准备
- [ ] 飞书多维表格已创建，表结构已按模板搭建
- [ ] 导入工具/插件已安装（Excel 对比导入插件）
- [ ] 备份原始 Excel 文件（复制一份，不修改原文件）
- [ ] 确定数据截止日期（如：2026-07-31 之前的数据迁移，8 月 1 日起走新系统）
### 2.3 数据备份
**严禁直接在原始 Excel 上操作！**
```
操作规范：
1. 将原始 Excel 复制为 "原始数据_备份_YYYYMMDD.xlsx"
2. 所有清洗操作在副本上进行
3. 保留原始文件至少 3 个月
```

## 3. 数据清洗规则
### 3.1 通用清洗规则
| 数据类型 | 清洗规则 | 示例 |
|---------|---------|------|
| 日期 | 统一为 YYYY-MM-DD 格式 | 2026/8/1 → 2026-08-01 |
| 金额 | 去除千分位逗号，保留 2 位小数 | 1,234,567.89 → 1234567.89 |
| 电话号码 | 去除空格和横杠 | 138-0000-0000 → 13800000000 |
| 邮箱 | 去除首尾空格，统一小写 | " Test@Email.com " → test@email.com |
| 文本 | 去除首尾空格 | " 供应商A " → 供应商A |
### 3.2 采购数据专项清洗规则
#### 供应商数据清洗
| 清洗项 | 规则 | 处理方式 |
|--------|------|---------|
| 供应商名称 | 统一为公司全称 | 与营业执照核对 |
| 供应商编码 | 如原系统有编码则保留，否则后续在多维表格中自动生成 | 新建编码字段留空 |
| 统一社会信用代码 | 18 位校验 | 用公式校验位数是否正确 |
| 供应商类型 | 标准化为单选值 | 建立映射：代工厂→代工厂、OEM→代工厂、原料商→原料供应商 |
| 合作状态 | 标准化为单选值 | 建立映射：在用→合作中、停止→淘汰、潜在→潜在 |
| 供应商等级 | 标准化为单选值 | S/A/B/C/D 五级 |
| 联系人 | 一个字段一个人 | 如有多人，取主要联系人，其余放备注 |
| 地址 | 省市区+详细地址 | 拆分为标准格式 |
#### 采购订单数据清洗
| 清洗项 | 规则 | 处理方式 |
|--------|------|---------|
| 订单编号 | 统一格式 PO-YYYYMMDD-XXX | 如有多种格式，统一转换 |
| 供应商 | 使用供应商全称（与供应商档案表一致） | 简称→全称映射 |
| 物料名称 | 统一命名 | 同一种物料可能有多个名称，需合并 |
| 规格型号 | 标准化格式 | 如：500ml/瓶 → 统一为 500mL/瓶 |
| 金额 | 确保单价×数量=总价 | 不一致的标记待确认 |
| 订单状态 | 标准化为单选值 | 建立映射：完成→已完成、取消→已取消 |
| 日期 | 确保在合理范围内 | 未来日期标记待确认 |
#### 合同数据清洗
| 清洗项 | 规则 | 处理方式 |
|--------|------|---------|
| 合同编号 | 统一格式 CON-YYYY-XXX | 如有多种格式统一转换 |
| 合同金额 | 确保数值正确 | 含"万"字的转换为数字 |
| 日期字段 | 生效日期 ≤ 到期日期 | 不一致的标记异常 |
| 合同状态 | 标准化 | 建立映射：执行→执行中、过期→已到期 |
### 3.3 数据清洗检查清单
完成清洗后，逐项确认：
- [ ] 所有日期字段格式统一为 YYYY-MM-DD
- [ ] 所有金额字段为纯数字（无逗号、无"万"字）
- [ ] 所有单选字段值在标准值域范围内
- [ ] 供应商名称在所有表中一致（全称统一）
- [ ] 订单金额 = 单价 × 数量（校验一致性）
- [ ] 无空白必填字段（供应商名称、订单编号等）
- [ ] 无重复记录（同一供应商/订单/合同无重复）
- [ ] 关联数据一致（订单中的供应商在供应商表中存在）

## 5. 分步导入 SOP
### 5.1 导入顺序（严格按依赖关系）
**必须按以下顺序导入，先导入的被依赖表：**
```
第一步：基础数据表（无依赖）
  ├── 1. 供应商档案表
  └── 2. 物料分类管理台账
第二步：名录与合同（依赖第一步）
  ├── 3. 合格供应商名录（依赖供应商档案）
  └── 4. 合同管理台账（依赖供应商档案）
第三步：业务数据表（依赖第一、二步）
  ├── 5. 请购需求单
  ├── 6. 采购订单台账（依赖供应商档案 + 合同台账）
  └── 7. 库存预警管理表（依赖供应商档案 + 物料分类）
第四步：执行数据（依赖第三步）
  ├── 8. 到货明细表（依赖采购订单 + 供应商档案）
  ├── 9. 到货异常台账（依赖到货明细 + 供应商档案）
  └── 10. 委外订单台账（依赖供应商档案 + 物料分类）
第五步：财务数据（依赖第三、四步）
  ├── 11. 对账发票结算台账（依赖采购订单 + 供应商档案）
  └── 12. 应付账款预测台账（依赖供应商档案 + 合同台账）
第六步：分析与评估表（依赖前五步数据）
  ├── 13. 供应商绩效评定表
  ├── 14. 降本追踪表
  ├── 15. 风险评估矩阵表
  ├── 15a. 风险问题台账（依赖风险评估矩阵表）
  ├── 16. 品类策略管理表
  ├── 17. 需求预测表
  ├── 18. ESG 评估表
  ├── 19. 谈判管理表
  ├── 20. 供应商协同创新表
  ├── 21. 合规检查表
  ├── 22. 人员能力评估表
  └── 23. 采购进度管理表
```
> 📌 **导入条目与标准表库口径**：以上共 24 个导入条目，对应 table-templates.md 的 **23 类标准表 / 物理表 25 张**——条目 8/9 = 第 6 类「到货明细与异常台账」的两张子表（6a/6b）分两条导入；条目 23 = 第 10 类「采购进度管理表（PMP）」的项目总览表（10a），任务明细（10b）随项目建立、无需预导入；条目 15a = 第 11 类「风险问题台账」。
### 5.2 单表导入操作步骤
```
步骤 1：关闭该表的所有自动化触发器（防止导入时误触发通知）
步骤 2：使用「Excel 对比导入」插件
  - 选择多维表格目标表
  - 上传清洗后的 Excel 文件
  - 系统自动匹配列名（参照映射对照表微调）
  - 预览差异，确认无误后执行导入
步骤 3：检查导入结果
  - 记录数是否与 Excel 一致
  - 字段类型是否正确（日期/金额/单选等）
  - 空值是否符合预期
步骤 4：重建关联字段
  - 导入后关联字段会丢失（变成文本值）
  - 手动将文本字段转为关联字段
  - 关联对应的目标表
步骤 5：验证公式字段
  - 公式字段不参与导入
  - 确认公式字段在导入后正常计算
  - 抽查 5-10 条记录验证公式结果
步骤 6：恢复自动化触发器（全部导入完成后再统一恢复）
```
### 5.3 导入注意事项
| 注意事项 | 说明 |
|---------|------|
| 先关自动化 | 导入前必须关闭所有自动化，否则批量新增会触发大量通知 |
| 关联字段后建 | 先导入为文本字段，所有基础表导入完成后再统一转为关联字段 |
| 公式不导入 | 公式字段在多维表格中预设，导入不影响 |
| 人员字段 | 需对应飞书账号，无法匹配的改为文本字段 |
| 附件字段 | 附件需单独上传，不支持 Excel 批量导入 |
| 自动编号 | 自动编号字段从导入后下一条记录开始编号 |

## 6. 导入后数据校验
### 6.1 数据完整性校验
| 校验项 | 方法 | 通过标准 |
|--------|------|---------|
| 记录数一致 | Excel 行数 vs 多维表格记录数 | 完全一致 |
| 必填字段无空值 | 筛选空值记录 | 0 条空值 |
| 关联字段有效 | 点击关联字段检查跳转 | 100% 可跳转 |
| 公式计算正确 | 抽查 10 条记录的公式结果 | 与 Excel 手算一致 |
### 6.2 数据准确性校验
| 校验项 | 方法 | 通过标准 |
|--------|------|---------|
| 金额计算 | 单价×数量=总价 | 0 条不一致 |
| 日期逻辑 | 生效日期≤到期日期 | 0 条异常 |
| 状态值域 | 所有单选字段在标准范围内 | 0 条超范围 |
| 供应商一致性 | 订单中的供应商都在供应商表中 | 0 条不匹配 |
| 重复检查 | 使用「删除重复记录」插件检查 | 0 条重复 |
### 6.3 校验方法
**方法一：人工抽查**
- 随机抽取 10% 的记录
- 与原始 Excel 逐字段对比
- 重点检查金额、日期、关联关系
**方法二：公式校验**
- 在多维表格中创建校验视图
- 用公式标记异常记录（如金额为负、日期逻辑错误）
- 筛选异常记录逐一修正
**方法三：对比工具**
- 使用「Excel 对比导入」插件的差异对比功能
- 导入前后数据量、关键指标对比

## 7. 并行运行期保障
### 7.1 并行运行策略
```
并行周期：1-2 周
并行内容：
  - 新系统（多维表格）与旧系统（Excel）同时记录
  - 每日对比两边数据一致性
  - 发现问题及时修正
```
### 7.2 每日对比检查
| 检查项 | 频率 | 负责人 | 处理方式 |
|--------|------|--------|---------|
| 新增订单数 | 每日 | 采购员 | Excel 新增数 vs 系统新增数 |
| 到货记录数 | 每日 | 仓管员 | Excel 新增数 vs 系统新增数 |
| 异常处理状态 | 每日 | 采购员 | 两边状态是否一致 |
| 库存数据 | 每日 | 仓管员 | 关键物料库存量对比 |
### 7.3 数据一致性处理
发现不一致时的处理流程：
```
发现差异 → 判断哪边正确 → 
  ├── 系统正确 → 更新 Excel，确认系统无误
  ├── Excel正确 → 检查系统录入是否遗漏，补录
  └── 两边都不对 → 追溯原始单据，以原始单据为准
```
### 7.4 正式切换标准
满足以下条件后可正式切换到新系统：
- [ ] 并行运行 ≥1 周
- [ ] 连续 3 天数据一致性 ≥98%
- [ ] 所有用户已能独立操作系统
- [ ] 关键报表可从系统直接输出
- [ ] 自动化触发器运行正常
### 7.5 切换后收尾
- [ ] 旧 Excel 标记为"历史数据（只读）"
- [ ] 所有自动化触发器恢复正常
- [ ] 历史数据加"历史"标记
- [ ] 通知所有相关人员正式切换
- [ ] 保留旧 Excel 至少 3 个月作为回退备份

## 8. 常见问题与解决方案
### 8.1 导入相关
| 问题 | 原因 | 解决方案 |
|------|------|---------|
| 日期导入后显示异常 | Excel 日期格式不统一 | 导入前统一为 YYYY-MM-DD 文本格式 |
| 金额多出小数位 | Excel 计算精度问题 | 导入前统一保留 2 位小数 |
| 单选字段出现"其他" | 原值不在标准值域内 | 检查映射关系，补充缺失值 |
| 关联字段导入后变文本 | 关联字段不支持直接导入 | 先导入为文本，后手动转为关联 |
| 人员字段匹配失败 | 文本姓名无法对应飞书账号 | 改用文本字段，或使用飞书 ID 导入 |
### 8.2 数据质量相关
| 问题 | 原因 | 解决方案 |
|------|------|---------|
| 同一供应商多个名称 | 简称/全称混用 | 建立名称映射表，统一为全称 |
| 订单金额与对账金额不一致 | 含税/不含税混淆 | 明确标注含税金额和不含税金额 |
| 历史订单状态不明确 | 缺少状态更新 | 统一标记为"已完成"或"历史" |
| 物料编码不统一 | 多套编码体系并存 | 建立新旧编码映射表 |
### 8.3 并行运行相关
| 问题 | 原因 | 解决方案 |
|------|------|---------|
| 两边数据不一致 | 录入时间差或遗漏 | 每日固定时间点对比，以原始单据为准 |
| 用户抵触新系统 | 操作习惯改变 | 分批培训，设置 1 周适应期 |
| 重复录入工作量大 | 并行期需要两边记录 | 缩短并行期至 1 周，集中精力 |

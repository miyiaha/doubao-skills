### 1.2 组件配置详情
#### KPI 卡片配置
| 卡片名称 | 数据源 | 聚合方式 | 筛选条件 | 格式 |
|---------|--------|---------|---------|------|
| 本月采购总额 | 采购订单台账 | SUM(总价含税) | 订单日期 = 本月 | 货币，千分位 |
| 活跃供应商数 | 供应商档案表 | COUNT | 合作状态 = "合作中" | 整数 |
| 合同到期预警 | 合同管理台账 | COUNT | 合同状态="执行中" AND 到期日期 ≤ 今天+60天 | 整数，红色底色 |
| 异常待处理 | 到货异常台账 | COUNT | 处理状态 = "待处理" 或 "处理中" | 整数，橙色底色 |
#### 折线图配置
| 配置项 | 值 |
|--------|-----|
| X 轴 | 订单日期（按月分组） |
| Y 轴 | SUM(总价含税) |
| 筛选条件 | 订单日期 ≥ 近12个月 |
| 数据标签 | 显示 |
| 趋势线 | 线性趋势 |
#### 饼图配置
| 配置项 | 值 |
|--------|-----|
| 维度 | 物料大类（从物料分类台账查找引用） |
| 度量 | SUM(总价含税) |
| 筛选条件 | 订单日期 = 近12个月 |
| 排序 | 从大到小 |
| 数据标签 | 显示名称+百分比 |
#### 散点图（卡拉杰克矩阵）配置
| 配置项 | 值 |
|--------|-----|
| X 轴 | 近12个月采购金额（数值型，对数刻度） |
| Y 轴 | 风险等级（映射为数值：高=3，中=2，低=1） |
| 维度 | 物料名称（作为气泡标签） |
| 气泡大小 | 供应商数量 |
| 颜色 | 卡拉杰克矩阵分类（战略/杠杆/瓶颈/常规） |
| 四象限辅助线 | X = 品类阈值，Y = 2（中风险线） |

### 2.2 组件配置详情
#### 订单状态分布饼图
| 配置项 | 值 |
|--------|-----|
| 维度 | 订单状态 |
| 度量 | COUNT |
| 颜色方案 | 待审批=灰 / 已审批=蓝 / 已下单=橙 / 部分到货=紫 / 已完成=绿 / 已取消=红 |
| 数据标签 | 显示数量+百分比 |
#### 到货准时率趋势折线图
> ⚠️ **飞书限制与变通**：仪表盘度量不支持 `COUNTIF(延迟天数=0) / COUNT` 这类公式比率运算，需先把比率落成字段再度量——在采购订单台账新建 0/1 公式字段「是否准时」（完整定义与口径见 formulas-automations.md 1.4），图表直接取其平均值。
| 配置项 | 值 |
|--------|-----|
| X 轴 | 计划到货日期（按周分组） |
| Y 轴 | 是否准时-平均值（0/1 字段，平均值即准时率，格式化为百分比） |
| 筛选条件 | 计划到货日期 ≥ 近12周；已到货订单（实际到货日期非空） |
| 参考线 | Y=95%（目标线） |
| 数据标签 | 显示百分比 |
#### 供应商绩效排名
| 配置项 | 值 |
|--------|-----|
| Y 轴 | 供应商名称 |
| X 轴 | 加权总分 |
| 筛选条件 | 评定周期 = 最新季度 |
| 排序 | 从高到低 |
| 颜色 | ≥90=绿 / 80-89=蓝 / 70-79=黄 / <70=红 |
| 数据标签 | 显示分数+等级 |
#### 我的待办任务看板（订单）
> ⚠️ **飞书限制与变通**：仪表盘图表仅支持**单数据表**数据源，不支持多表汇总，原"多表汇总"数据源不可实现。本组件改为聚焦订单待办；对账差异、异常关闭两类待办分别由组件 3/4 的 KPI 卡片承接（点击卡片下钻到对应表过滤视图），不要把多张表合并进一个看板。
| 配置项 | 值 |
|--------|-----|
| 数据源 | 采购订单台账 |
| 视图分组 | 订单状态：待审批 / 已审批 / 已下单 / 部分到货 |
| 筛选条件 | 订单状态 != 已完成 AND 订单状态 != 已取消 |
| 卡片字段 | 订单编号 / 供应商 / 物料名称 / 计划到货日期 / 采购员 |
#### 新品质量专项列表
| 配置项 | 值 |
|--------|-----|
| 数据源 | 到货明细表 |
| 筛选条件 | 是否新品首批 = 已勾选（复选框字段，定义见 table-templates.md 表 6a） |
| 显示字段 | 入库单号 / 物料名称 / 供应商 / 到货数量 / 合格数量 / 质检结论 |
| 质量跟踪 | 合格情况以"合格数量 / 到货数量"两列对照展示；来料合格率公式见 formulas-automations.md 1.4 |

### 3.2 组件配置详情
#### 年度累计节约额
| 配置项 | 值 |
|--------|-----|
| 数据源 | 降本追踪表 |
| 聚合 | SUM(年化节约额) |
| 筛选 | 实施日期 ≥ 本年1月1日 |
| 对比 | vs 去年同期（如有上年数据） |
| 格式 | 货币，万为单位 |
| 颜色 | 达标=绿 / 未达标=红 |
#### 降本类型分布饼图
| 配置项 | 值 |
|--------|-----|
| 维度 | 降本类型 |
| 度量 | SUM(年化节约额) |
| 筛选 | 本年数据 |
| 颜色 | 价格谈判=蓝 / 替代物料=绿 / 工艺优化=橙 / 批量折扣=紫 / 物流优化=青 / 付款条件=灰 |
| 数据标签 | 显示类型+金额+占比 |
#### 供应商降本贡献排名
| 配置项 | 值 |
|--------|-----|
| Y 轴 | 供应商名称 |
| X 轴 | SUM(年化节约额) |
| 排序 | 从高到低 |
| 颜色 | 绿色渐变（金额越大越深） |
| 数据标签 | 显示金额 |
#### 品类降本完成率
> ⚠️ **飞书限制与变通**：仪表盘度量不支持"实际节约额 / 年度降本目标"这类跨字段比率运算，且降本追踪表中不存在「实际节约额」「年度降本目标」字段。变通做法是把比率落成公式字段再度量：在品类策略管理表补建「关联降本项目」双向关联 + 「累计节约额」查找引用 + 「品类降本完成率」公式字段（字段定义见 table-templates.md 第 18 节），本组件直接度量该公式字段；降本明细仍在降本追踪表维护，通过双向关联回写汇总。
| 配置项 | 值 |
|--------|-----|
| X 轴 | 品类名称 |
| Y 轴 | 品类降本完成率-平均值（公式字段，存 0-100，格式化为百分比） |
| 参考线 | 100%（目标线） |
| 颜色 | ≥100%=绿 / 80-99%=黄 / <80%=红 |

## 6. 仪表盘导出与分享
### 6.1 导出方式
| 方式 | 操作路径 | 适用场景 |
|------|---------|---------|
| 截图分享 | 仪表盘右上角 → 分享 → 截图 | 快速分享到飞书群/聊天 |
| 导出PDF | 仪表盘 → 导出 → 打印 → 另存为PDF | 正式报告、存档 |
| 链接分享 | 仪表盘 → 分享 → 生成链接 | 飞书内部协作查看 |
| 嵌入飞书文档 | 飞书文档 → 插入 → 多维表格 → 选择仪表盘 | 嵌入月度报告 |
### 6.2 定期自动推送
通过智能体配置，实现仪表盘关键数据定期推送：
| 推送频率 | 推送内容 | 推送对象 |
|---------|---------|---------|
| 每日 | KPI卡片异常数据 | 采购员 |
| 每周 | 待处理事项汇总 | 采购主管 |
| 每月 | 仪表盘导出 PDF 或分享链接 + 数据分析 | 采购经理/总监 |
| 每季度 | 绩效评定结果+趋势分析 | 管理层 |
> 说明：智能体可直接读取多维表格数据并推送消息（KPI 异常、待办汇总等），但**无法对仪表盘页面截图**；周期性可视化推送请使用 6.1 的"导出 PDF"或"链接分享"，由人工导出后随智能体消息一并发出。
### 6.3 仪表盘搭建顺序建议
```
步骤 1：先搭建数据源表（确保数据准确）
步骤 2：搭建 KPI 卡片（4个核心指标）
步骤 3：搭建趋势图（折线图/柱状图）
步骤 4：搭建分布图（饼图/散点图）
步骤 5：搭建列表区（TOP 10 / 预警清单）
步骤 6：配色美化（按配色方案统一颜色）
步骤 7：验证数据准确性（与源表手工核对）
步骤 8：配置分享和推送
```

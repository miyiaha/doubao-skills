## 1. 常用公式模板
> ### 📋 复制须知（使用本节公式前必读）
>
> 本节公式按飞书多维表格官方函数语法编写，直接复制可用。请注意以下约定：
>
> 1. **运算符写法**：乘用 `*`、除用 `/`、幂用 `^`（或 `POWER(x, n)`）；比较用 `>=`、`<=`、`!=`（官方确认的不等于写法为 `!=`）。文档示例中如出现 × ÷ ≥ ≤ ≠ 等数学符号，仅为排版易读，**实际输入时一律替换为 `*` `/` `>=` `<=` `!=`**。
> 2. **百分比口径**：全包统一为 **0-100 数字**（如 95 代表 95%），公式直接写 `>= 90`，不要写 `>= 90%`。若希望单元格显示为"95%"样式，将字段/单元格格式设置为百分比即可（飞书会按 0-100 数字显示，或存 0.95 显示 95%，二选一后全表统一，本包统一存 0-100 数字 + 单元格格式设为百分比）。
> 3. **跨表统计**：飞书**不支持** Excel 三参数写法 `SUMIF(范围, 条件, 求和范围)`，也**不支持 SUMIFS / COUNTIFS / AVERAGEIFS / AVERAGEIF**。跨表统计请用官方 `FILTER` + 聚合（`.SUM()` / `.COUNT()` / `.AVERAGE()`）配合 `CurrentValue` 的写法，见 1.6、1.15 示例。
> 4. **查找引用字段**：查找引用（LOOKUP）返回的是**数组**，直接参与 `MAX/ABS/DATEDIF` 等算术会得到异常结果，需先用 `.SUM()` / `.MIN()` / `.FIRST()` 等聚合取值（详见各公式处的 ⚠️ 提示）。
> 5. **DATEDIF 参数约束**：飞书官方要求 **结束日期必须晚于起始日期**。因此"已过期"判断**不能**依赖 DATEDIF 返回负数，必须先用日期比较（如 `到期日期 < TODAY()`）前置处理过期分支，DATEDIF 只在未过期分支使用（见 1.2）。
> 6. **空值判断**：空值用 `ISBLANK(字段)` 或与空字符串 `""` 比较（官方 FAQ 口径），不要使用 `BLANK()` 函数。
### 1.1 金额计算类
**含税总价**
```
数量 * 单价
```
**不含税价格**
```
总价 / (1 + 税率数值)
```
> ⚠️ 注意：税率在主表中为单选文本（如"13%"），需先建一个辅助公式字段「税率（数值）」用 IF 转换为小数（如 0.13），再参与除法计算。公式：`IF(税率="13%", 0.13, IF(税率="9%", 0.09, ...))`
**对账差额**
```
对账金额 - 发票金额
```
差额 ≠ 0 时高亮显示，提示需核查。
**待付金额**
```
应付金额 - 已付金额
```
**加工费总价（委外）**
```
实际完成数量 * 加工费单价
```
**TCO 总拥有成本（年度）**
```
年采购金额 + 年质检成本 + 年物流成本 + 年库存持有成本 + 年应急处理成本
```
说明：TCO 不仅看采购单价，还包含质量返工、物流延误、超额库存等隐性成本。与降本追踪表配合使用，衡量降本措施的真实效果。
**年化节约额**
```
(原单价 - 现单价) * 年采购量
```
**降本率**
```
IF(原单价 > 0, (原单价 - 现单价) / 原单价 * 100, 0)
```
**健康降本判定**
```
IF(质量影响评估 = "无影响" AND 交付影响评估 = "无影响", "✅ 健康降本", "⚠️ 需关注")
```
降本不能以牺牲质量和交付为代价，需持续监控。
### 1.2 日期与预警类
> ⚠️ **飞书官方 DATEDIF 参数约束**：结束日期必须晚于起始日期。已过期记录（到期日期 < TODAY()）调用 `DATEDIF(TODAY(), 到期日期, "D")` 违反约束、不会返回负数。因此下列公式统一采用**"先日期比较处理过期，DATEDIF 只在未过期分支使用"**的结构，请勿改回负数判断写法。
**合同到期倒计时（天，未过期时有效）**
```
IF(到期日期 < TODAY(), 0, DATEDIF(TODAY(), 到期日期, "D"))
```
已过期记录返回 0（如需显示负数可改用差值写法 `到期日期 - TODAY()`，飞书日期字段直接相减返回天数，支持负值）。
**续签提醒标记**
```
IF(到期日期 < TODAY(), "🔴 已过期",
   IF(DATEDIF(TODAY(), 到期日期, "D") <= 60, "⚠️ 即将到期", "✅ 正常"))
```
> ⚠️ 注意：过期分支必须用日期比较 `到期日期 < TODAY()` 前置判断，再进入 DATEDIF 的 60 天分支，顺序不可颠倒，否则已过期合同会违反 DATEDIF 参数约束导致公式报错。
**延迟天数**
```
IF(实际到货日期 > 计划到货日期,
   DATEDIF(计划到货日期, 实际到货日期, "D"),
   0)
```
**资质有效期预警**
```
IF(有效期至 < TODAY(), "🔴 已过期",
   IF(DATEDIF(TODAY(), 有效期至, "D") <= 30, "⚠️ 即将过期", "✅ 有效"))
```
> ⚠️ 注意：与续签提醒相同，先用 `有效期至 < TODAY()` 前置处理过期分支，DATEDIF 只在未过期分支使用；判断顺序不可颠倒。
### 1.3 库存管理类
**可用天数**
```
IF(日均消耗量 > 0, 当前库存 / 日均消耗量, "∞")
```
**库存预警状态**
```
IF(当前库存 < 安全库存, "🔴 低库存",
   IF(当前库存 > 最高库存, "🟡 超储", "🟢 正常"))
```
**补货建议量**
```
MAX(0, 安全库存 * 2 - 当前库存)
```
### 1.4 绩效与评分类
**供应商加权总分**
```
质量得分 * 0.35 + 交付得分 * 0.25 + 服务得分 * 0.20 + 价格得分 * 0.20
```
**绩效评定等级判定（分数口径，用于绩效评定表「评定等级」字段）**
```
IF(加权总分 >= 90, "S",
   IF(加权总分 >= 80, "A",
      IF(加权总分 >= 70, "B",
         IF(加权总分 >= 60, "C", "D"))))
```
> ⚠️ 区别于「供应商等级」：本公式输出的是绩效评定等级（季度考核分数口径）；供应商档案表的「供应商等级」（S战略/A核心/B合格/C备选/D淘汰）按供应占比/物料等级判定（见 SKILL.md 供应商分级体系）。两者字母相同但判定依据不同、各自独立计算，勿混用。
**来料合格率（记录级，单行计算）**
```
IF(到货数量 > 0, 合格数量 / 到货数量 * 100, 0)
```
存 0-100 数字（95 代表 95%），单元格格式设为百分比显示。
**准时交付率（整体统计，需辅助字段）**
> ⚠️ `延迟天数`/`实际到货日期` 是本行单值而非数组，`COUNTIF(延迟天数, 0) / COUNTA(实际到货日期)` 这种记录级写法在飞书中不可实现（结果恒为 0 或 100）。正确做法是**先建"是否准时"辅助字段，再做统计**：
第 1 步：在采购订单台账新增公式字段「是否准时」（数字，0/1）：
```
IF(OR(ISBLANK(实际到货日期), 实际到货日期 <= 计划到货日期), 1, 0)
```
（未到货或提前/准时到货计 1；已到货且晚于计划计 0。口径：仅统计已到货订单时，将未到货记录在仪表盘中用筛选排除即可。）
第 2 步：整体准时交付率二选一：
- **仪表盘方案（推荐）**：KPI 卡片选"是否准时-平均值"，将结果格式化为百分比（平均值 0.95 即 95%）；
- **公式方案**（在汇总位/负责人视图场景，跨表 FILTER 写法）：
```
采购订单台账.FILTER(CurrentValue.[是否准时] = 1).COUNT()
/ 采购订单台账.FILTER(NOT(ISBLANK(CurrentValue.[实际到货日期]))).COUNT() * 100
```
### 1.5 风险管理类
> 本节公式用于「风险评估矩阵表」（见 table-templates.md 第 17 节）。RPN 为 FMEA 三要素乘积，与「风险问题台账」的 3 级定性评估（概率×影响）是两套体系：RPN 定量优先用于供应链风险量化跟踪，风险问题台账用于项目执行中的轻量风险登记。
**RPN 风险优先数**
```
发生概率 * 影响程度 * 可检测性
```
发生概率、影响程度和可检测性均取值 1-5，RPN 范围 1-125。
> ⚠️ 注意：三个要素在表中为单选字段（文本值如"1-极低"），需在公式中先用 IF 转换为数字（如 `IF(发生概率="1-极低", 1, IF(发生概率="2-低", 2, ...))`），再相乘；或直接将三个字段设为 1-5 的数字/单选数字选项，省去转换。
**风险等级判定**
```
IF(RPN >= 80, "🔴 高风险",
   IF(RPN >= 40, "🟡 中风险", "🟢 低风险"))
```
> RPN 阈值参考：>=80 必须制定应急方案，每月跟踪；40-79 制定预案，每季度跟踪；<40 保持监控，半年评估一次。
**依赖度预警**
```
IF(单一供应商依赖度 >= 70, "🔴 过度依赖",
   IF(单一供应商依赖度 >= 50, "🟡 需关注", "🟢 正常"))
```
> 口径：单一供应商依赖度存 0-100 数字（70 代表 70%），单元格格式设为百分比显示。
**波动预警**
```
IF(价格波动率 > 15, "🔴 剧烈波动",
   IF(价格波动率 >= 5, "🟡 关注", "🟢 稳定"))
```
> 口径：价格波动率存 0-100 数字（15 代表 15%）。
### 1.6 ESG 评分类
> 💡 **ESG 评分说明**：本技能中 ESG 评分采用"表现越好，分数越高"的计分方式。环境、社会、治理三个维度分别按 0-100 分评估，分数越高代表该维度表现越好。
**ESG 总分**
```
环境得分 * 0.40 + 社会得分 * 0.30 + 治理得分 * 0.30
```
**ESG 等级判定**
```
IF(ESG总分 >= 80, "A",
   IF(ESG总分 >= 60, "B",
      IF(ESG总分 >= 40, "C", "D")))
```
> 等级含义：A 级（优秀，>=80分）> B 级（良好，60-79分）> C 级（合格，40-59分）> D 级（不合格，<40分）
**降本汇总（按供应商）**
> ⚠️ 飞书不支持 Excel 三参数写法 `SUMIF(范围, 条件, 求和范围)`，跨表汇总请用 FILTER + 聚合的官方语法。
写法一（FILTER 函数，在供应商档案表的公式字段中使用）：
```
SUM(FILTER(降本追踪表.[年化节约额], 降本追踪表.[供应商] = [供应商名称]))
```
写法二（CurrentValue 链式写法）：
```
[降本追踪表].FILTER(CurrentValue.[供应商] = [供应商名称]).[年化节约额].SUM()
```
> 两种写法等效，任选其一。前提：供应商档案表与降本追踪表已建立关联字段（或 FILTER 中引用的两表字段可跨表取数）。`[供应商名称]` 为当前表（供应商档案表）字段，`降本追踪表.[供应商]` 为目标表字段。更简单的替代方案：在降本追踪表的「供应商」关联字段上直接加一个"查找引用"字段取年化节约额，再用 SUM 聚合。
### 1.7 项目进度类（PMP）
> ⚠️ SPI 公式依赖项目总览表中的 EV/PV 辅助字段，字段定义见 table-templates.md 第 10a 节（项目预算 BAC、计划完成百分比、挣值 EV、计划值 PV），请先按模板补齐字段再配置公式。
**挣值 EV（项目总览表公式字段）**
```
完成百分比 * 项目预算BAC
```
> 完成百分比/计划完成百分比使用飞书"进度"字段（存储 0-1 小数，界面显示为百分比），因此直接乘以预算即得金额，无需再除以 100。
**计划值 PV（项目总览表公式字段）**
```
计划完成百分比 * 项目预算BAC
```
**SPI 进度绩效指数（项目总览表公式字段）**
```
IF(PV > 0, EV / PV, 1)
```
> 注意：PV=0 时（项目未开始）SPI 返回 1，表示进度正常。
**SPI 状态判定**
```
IF(SPI >= 1, "🟢 正常",
   IF(SPI >= 0.9, "🟡 轻微滞后", "🔴 严重滞后"))
```
**任务完成偏差天数（10b 任务明细表公式字段）**
```
IF(ISBLANK(实际完成), "", DATEDIF(计划完成, 实际完成, "D"))
```
> 日期字段相减也可直接写 `实际完成 - 计划完成`，返回天数且支持负值（提前完成为负），DATEDIF 写法则要求实际完成晚于计划完成，已提前完成的记录需按上文前置判断处理。
### 1.8 品类策略类
**卡拉杰克象限自动判定**
> ⚠️ 前置字段（v2.1.2 已补齐到 table-templates.md 第 18 节品类策略管理表）：本公式引用「品类阈值（数字）」「风险等级（单选 高/中/低）」两个字段，搭建时须先创建这两个字段（并填写各品类支出阈值），再配置象限公式，否则公式无法引用会报错。
```
IF(年采购金额 >= 品类阈值（数字） AND 风险等级 = "高", "战略型",
   IF(年采购金额 >= 品类阈值（数字） AND 风险等级 = "低", "杠杆型",
      IF(年采购金额 < 品类阈值（数字） AND 风险等级 = "高", "瓶颈型", "常规型")))
```
**策略匹配度评分**
```
IF(象限 = "战略型" AND AND(供应商数量 >= 2, 供应商数量 <= 3) AND OR(合同期限建议 = "3年", 合同期限建议 = "5年"), "✅ 策略匹配",
   IF(象限 = "杠杆型" AND 供应商数量 >= 3 AND OR(合同期限建议 = "1年", 合同期限建议 = "2年"), "✅ 策略匹配",
      IF(象限 = "瓶颈型" AND 供应商数量 >= 2 AND OR(合同期限建议 = "1年", 合同期限建议 = "2年", 合同期限建议 = "3年"), "✅ 策略匹配",
         IF(象限 = "常规型" AND 供应商数量 = 1, "✅ 策略匹配", "⚠️ 需调整策略"))))
```
> 策略匹配逻辑说明：
> - 战略型：需要深度绑定，2-3家供应商确保双源供应，长周期合同（3-5年）
> - 杠杆型：利用竞争压价，至少3家供应商充分竞争，中短周期合同（1-2年）
> - 瓶颈型：供应风险高，至少2家供应商降低断供风险，灵活合同（1-3年）便于调整
> - 常规型：低价值低风险，1家供应商简化流程即可
**供应商份额分配合理性检查**
```
IF(象限 = "战略型" AND 供应商数量 < 2, "🔴 风险：战略品类需双源供应",
   IF(象限 = "杠杆型" AND 供应商数量 < 3, "🟡 建议增加竞争供应商",
      IF(象限 = "瓶颈型" AND 供应商数量 < 2, "🔴 风险：瓶颈品类需备选供应商",
         IF(象限 = "瓶颈型" AND 供应商数量 = 0, "🔴 紧急：无可用供应商", "🟢 合理"))))
```
### 1.9 需求预测类
**加权基础预测**
```
近3月月均用量 * 0.5 + 3-6月月均用量 * 0.3 + 6-12月月均用量 * 0.2
```
**季节调整后预测**
```
基础预测值 * 季节因子
```
**最终预测值**
```
季节调整后预测 * 市场趋势系数
```
**预测偏差率**
```
IF(实际需求量 > 0, ABS(最终预测值 - 实际需求量) / 实际需求量 * 100, 0)
```
> 注意：实际需求量为 0 时偏差率返回 0，避免除零报错。
**预测准确率**
```
MAX(0, 100 - 预测偏差率)
```
> 口径：预测偏差率/预测准确率均为 0-100 数字（90 代表 90%），单元格格式设为百分比显示。当偏差率超 100（预测严重偏离）时准确率钳制为 0，避免出现负值。
**预测准确率等级**
```
IF(预测准确率 >= 90, "🟢 高",
   IF(预测准确率 >= 70, "🟡 中", "🔴 低"))
```
**建议采购量**
```
MAX(0, 最终预测值 - 当前库存 + 安全库存)
```
> ⚠️ 查找引用返回数组：需求预测表的「当前库存」来自库存预警管理表的查找引用（返回数组）。若一个物料在库存表中有多条记录，需先聚合取值再参与运算，如 `MAX(0, 最终预测值 - 当前库存.SUM() + 安全库存)`；若为一对一关联可省略，但建议统一加 `.SUM()` 防御。
### 1.10 谈判管理类
> ⚠️ **字段前提**：本节公式依赖谈判管理表中的数字字段「目标价（数字）」「底线价（数字）」「最终成交价」「BATNA 价格」以及日期字段「谈判开始日期」「谈判结束日期」，字段定义见 table-templates.md 第 20 节（v2.1.1 起新增）。原「目标价/目标条件」等文本字段保留用于非价格谈判场景。
**谈判达成率**
```
IF(目标价（数字） != 底线价（数字）, (最终成交价 - 底线价（数字）) / (目标价（数字） - 底线价（数字）) * 100, 100)
```
说明：采购谈判场景中，目标价是期望达成的较低价格（采购方理想价），底线价是采购方愿接受的最高价格（谈判上限/底线）。因此目标价 < 底线价。
- 达成率 = 100：成交价恰好等于目标价
- 达成率 > 100：成交价低于目标价，对采购更有利
- 达成率 < 0：成交价高于底线价，谈判失败
- 当目标价等于底线价时默认返回 100
> 口径：达成率为 0-100 数字（100 代表 100%），单元格格式设为百分比显示。
> ⚠️ 注意：本公式仅适用于价格谈判场景，需将价格填入数字字段（目标价（数字）/底线价（数字）/最终成交价）；非价格谈判（如合同条款谈判）不适用此公式，相关条件仍记录在文本字段中。
**达成率评价**
```
IF(谈判达成率 > 100, "🏆 超预期",
   IF(谈判达成率 >= 80, "✅ 达成",
      IF(谈判达成率 >= 50, "⚠️ 基本达成", "❌ 未达成")))
```
**BATNA 差距（降本场景）**
```
最终成交价 - BATNA 价格
```
正值表示优于 BATNA，负值表示不如次优方案。`BATNA 价格` 为数字字段（货币），在价格谈判时填写；原「BATNA（最佳替代方案）」多行文本字段保留用于记录方案描述。
**谈判周期（天）**
```
IF(OR(ISBLANK(谈判开始日期), ISBLANK(谈判结束日期)), "", DATEDIF(谈判开始日期, 谈判结束日期, "D"))
```
> 「谈判开始日期」「谈判结束日期」两个日期字段已在 table-templates.md 第 20 节谈判管理表中定义（v2.1.1 起）；若从旧版模板搭建时缺失，需补建后再配置本公式。

**雷达图六维度评分准备**

**质量维度得分**
```
来料合格率 * 0.6 + (100 - 退货率) * 0.2 + IF(质量异常次数=0, 100, MAX(0, 100-质量异常次数*10)) * 0.2
```
> 口径：退货率存 0-100 数字，因此直接用 `100 - 退货率` 折算为得分。
**交付维度得分**
```
准时交付率 * 0.5 + 订单满足率 * 0.3 + IF(紧急订单响应率>=90, 100, 紧急订单响应率/0.9*100) * 0.2
```
**价格维度得分**
```
IF(市场最低价>0, 市场最低价/该供应商单价*100, 80) * 0.5 + MIN(100, 降本率*10) * 0.3 + IF(付款条件评分>=80, 100, 付款条件评分/80*100) * 0.2
```
> 口径：降本率为 0-100 数字，`MIN(100, 降本率*10)` 将其映射为 0-100 得分（降本率 10% 及以上记满分）。
**服务维度得分**
```
IF(平均响应时间<=4, 100, MAX(0, 100-(平均响应时间-4)*5)) * 0.4 + 问题解决率 * 0.3 + 技术支持满意度 * 0.3
```
**创新维度得分**
```
IF(协同创新项目数>=3, 100, 协同创新项目数/3*100) * 0.4 + 新品配合度 * 0.3 + 技术改进建议采纳率 * 0.3
```
**合规维度得分**
```
IF(合规事件数=0, 100, MAX(0, 100-合规事件数*20)) * 0.4 + 资质完整率 * 0.3 + IF(ESG等级="A", 100, IF(ESG等级="B", 80, IF(ESG等级="C", 60, 40))) * 0.3
```
**雷达图综合得分（用于仪表盘展示）**
```
质量维度*0.25 + 交付维度*0.20 + 价格维度*0.15 + 服务维度*0.15 + 创新维度*0.15 + 合规维度*0.10
```
> 💡 仪表盘展示建议：使用六维雷达图展示单个供应商的能力分布，或使用堆叠雷达图对比 TOP 3 供应商。
### 1.13 采购成本结构分析（Should Cost 模型）
> Should Cost 模型帮助采购人员理解供应商报价的合理性，识别降本空间。适用于价格谈判前的准备阶段。
**成本结构分解表字段设计**（建议在降本追踪表或谈判管理表中新增以下字段）：
| 字段名 | 字段类型 | 说明 |
|--------|---------|------|
| Should Cost 分析编号 | 自动编号 | SC-0001 |
| 物料名称 | 文本 | — |
| 供应商报价 | 货币 | 供应商当前报价 |
| 原材料成本（估算） | 货币 | 根据公开原料价格估算 |
| 加工成本（估算） | 货币 | 根据工艺和工时估算 |
| 包装成本（估算） | 货币 | 根据包装规格估算 |
| 物流成本（估算） | 货币 | 根据运输距离和方式估算 |
| 管理费用分摊 | 货币 | 通常为制造成本的 5-15% |
| 合理利润 | 货币 | 通常为总成本的 8-15% |
| Should Cost 总价 | 公式 | = 原材料+加工+包装+物流+管理+利润 |
| 报价偏差率 | 公式 | = (供应商报价-Should Cost总价)/Should Cost总价*100 |
| 偏差判定 | 公式 | = IF(报价偏差率>20, "🔴 报价偏高", IF(报价偏差率>10, "🟡 略偏高", IF(报价偏差率>-5, "🟢 合理", "⚠️ 低于成本"))) |
**管理费用估算公式**
```
(原材料成本+加工成本) * 0.1
```
> 默认按 10% 估算，可按行业调整（制造业 5-10%，化妆品代工 8-12%）
**合理利润估算公式**
```
(原材料成本+加工成本+包装成本+物流成本+管理费用) * 0.1
```
> 默认按 10% 利润率估算，可根据供应商议价能力调整（5-15%）
**Should Cost 总价**
```
原材料成本+加工成本+包装成本+物流成本+管理费用+合理利润
```
**报价偏差率**
```
IF(Should Cost总价>0, (供应商报价-Should Cost总价)/Should Cost总价*100, 0)
```
**偏差判定**
```
IF(报价偏差率 > 20, "🔴 报价偏高，有 20% 以上议价空间",
   IF(报价偏差率 > 10, "🟡 略偏高，有 10-20% 议价空间",
      IF(报价偏差率 > -5, "🟢 报价合理",
         "⚠️ 低于成本，需警惕质量风险")))
```

### 1.15 采购效率分析（PR→PO / PO→收货周期）
> 衡量采购部门的工作效率和供应商的交付效率。
>
> **📋 前置字段清单**：本节公式引用的「请购日期」来自请购需求单，「订单日期」「实际到货日期」来自采购订单台账。跨表取数时需先在当前表建立对应关联字段 + 查找引用字段（如通过订单编号将请购单与订单关联后，用查找引用把订单日期带入请购单），公式中的字段名指查找引用带入后的字段。

```
IF(OR(ISBLANK(请购日期), ISBLANK(订单日期)), "", DATEDIF(请购日期, 订单日期, "D"))
```
> 说明：请购日期来自请购需求单，订单日期来自采购订单台账，通过关联字段+查找引用获取；DATEDIF 要求结束日期晚于起始日期，此处订单日期必然晚于请购日期，安全。空值用 ISBLANK 判断（官方 FAQ 口径，不要用 BLANK() 函数）。
**PR→PO 效率评级**
```
IF(PR_PO周期<=1, "🟢 极快",
   IF(PR_PO周期<=3, "🟢 正常",
      IF(PR_PO周期<=5, "🟡 偏慢", "🔴 超时")))
```
**PO→收货周期（天）**
```
IF(OR(ISBLANK(订单日期), ISBLANK(实际到货日期)), "", DATEDIF(订单日期, 实际到货日期, "D"))
```
**PO→收货效率评级**
```
IF(PO_收货周期<=采购提前期, "🟢 提前/准时",
   IF(PO_收货周期<=采购提前期+3, "🟡 轻微延迟", "🔴 严重延迟"))
```

```
IF(AND(PR_PO效率评级="🟢 极快", PO_收货效率评级="🟢 提前/准时"), "⭐ 优秀",

### 1.16 供应商集中度分析（HHI 指数）
> HHI（Herfindahl-Hirschman Index）用于衡量供应商集中度，判断是否存在过度依赖单一供应商的风险。HHI 范围 0-10000，越接近 10000 表示垄断程度越高。
>
> **📋 前置字段清单**（两种实现方案二选一）：
>
> - **方案 A（推荐，供应商份额子表）**：新建「供应商份额」表，字段：品类（关联品类策略管理表）、供应商（关联供应商档案表）、该供应商采购额（数字/货币，统计周期内）、品类总采购额（数字/货币，可由品类侧汇总带出）、供应商份额占比（公式，见下）。每行 = 一个品类 × 一个供应商。HHI/最大依赖度在该子表或品类策略管理表中按品类汇总计算。
> - **方案 B（小规模，字段组）**：直接在品类策略管理表中新增数字字段「份额-供应商1」～「份额-供应商4」（0-100 数字，如 60 代表 60%，见 table-templates.md 第 18 节 v2.1.1 新增字段），适用于供应商数量 ≤4 的品类；HHI = 各份额的平方和。
**供应商份额占比（方案 A，供应商份额子表公式字段）**
```
IF(品类总采购额>0, 该供应商采购额/品类总采购额*100, 0)
```
> 口径：份额占比存 0-100 数字。品类总采购额可通过查找引用从品类策略管理表获取（查找引用返回数组，若引用多条记录需加 `.SUM()` 聚合，如 `品类总采购额.SUM()`）。
**HHI 指数计算**
- 方案 A（份额子表内，按品类汇总位计算）：
```
份额占比字段 ^ 2 求和
```
即对同一品类下所有记录的「供应商份额占比」求平方和；在品类策略管理表侧可用 `供应商份额表.FILTER(CurrentValue.[品类] = [品类名称]).[供应商份额占比].SUM()` 无法直接平方，需在份额子表先建「份额平方」公式字段 `供应商份额占比 ^ 2`，再对该字段按品类 FILTER + SUM。
- 方案 B（品类策略管理表字段组，字段名以 table-templates.md 第 18 节为准）：
```
[份额-供应商1]^2 + [份额-供应商2]^2 + [份额-供应商3]^2 + [份额-供应商4]^2
```
> 实际操作示例：某品类 3 家供应商份额为 50/30/20（代表 50%、30%、20%），则 HHI = 50^2+30^2+20^2 = 2500+900+400 = 3800。
**HHI 集中度判定**
```
IF(HHI指数>=2500, "🔴 高度集中（垄断风险）",
   IF(HHI指数>=1500, "🟡 中度集中",
      IF(HHI指数>=1000, "🟢 适度集中", "🟢 充分竞争")))
```
> HHI 阈值参考：
> - HHI < 1000：充分竞争，供应商格局健康
> - 1000 ≤ HHI < 1500：适度集中，可接受
> - 1500 ≤ HHI < 2500：中度集中，需关注
> - HHI ≥ 2500：高度集中，存在供应风险
**最大供应商依赖度**
- 方案 A：份额子表按品类取 MAX（`供应商份额表.FILTER(...).[供应商份额占比].MAX()`，或在份额子表用仪表盘按品类分组取最大值）
- 方案 B：
```
MAX([份额-供应商1], [份额-供应商2], [份额-供应商3], [份额-供应商4])
```
**依赖度预警**
```
IF(最大供应商依赖度>=70, "🔴 严重依赖",
   IF(最大供应商依赖度>=50, "🟡 需关注",
      IF(最大供应商依赖度>=30, "🟢 适度", "🟢 分散")))
```
> 口径：依赖度为 0-100 数字（70 代表 70%）。与 1.5「依赖度预警」同口径，可在风险评估矩阵表与份额数据之间任选一处配置。
**建议行动**
```
IF(HHI指数>=2500, "⚡ 紧急：立即开发备选供应商，降低单一依赖",
   IF(HHI指数>=1500, "⚠️ 建议：启动备选供应商开发计划",
      IF(HHI指数>=1000, "📋 关注：监控最大供应商经营状况", "✅ 维持：供应商格局健康")))
```

- **触发器**：定时触发，每日 9:00
- **条件**：合同到期日期 ≤ 今天 + 60 天 AND 合同状态 = "执行中"
- **动作**：

> 注意：不直接修改合同状态，合同状态仅在合同到期/签署/终止时由人工或对应流程触发变更。

- **触发器**：当「当前库存」字段被修改时
- **条件**：当前库存 < 安全库存
- **动作**：
  1. 发送飞书消息给品类负责人
  2. 更新预警状态为"低库存"
  3. 自动创建请购需求单（预填物料信息）
### 2.3 到货异常自动通知（新增记录触发）
- **触发器**：到货异常台账新增记录时
- **条件**：异常类型包含"质量不合格"或"数量短缺"
- **动作**：
  1. 通知采购员和质量负责人
  2. 设置处理状态为"待处理"
  3. 关联到供应商绩效评定（扣分记录）
### 2.4 对账差异提醒（字段修改触发）
- **触发器**：发票金额字段被修改时
- **条件**：差额 ≠ 0
- **动作**：
  1. 通知经办人核查
  2. 标记为"待核查"状态
### 2.5 供应商资质到期预警（定时触发）
- **触发器**：定时触发，每周一 9:00

- **动作**：
  1. 通知供应商管理员
  2. 发送消息给对应供应商联系人（如已接入）
### 2.6 采购订单状态流转（字段修改触发）
- **触发器**：订单状态变更时
- **动作**（按状态分支）：
  - "已审批" → 通知供应商（如有外部接口）
  - "部分到货" → 检查剩余数量，通知仓管
  - "已完成" → 自动关联到对账台账
  - "已取消" → 通知财务释放预算
### 2.7 绩效评定自动汇总（定时触发）
- **触发器**：每季度末触发
- **飞书变通方案**：飞书自动化定时触发仅支持每天/每周/每月/每年/自定义间隔，无"每季度"选项。落地方式二选一：
  - **每月触发 + 季度月判断**：设每月 1 日 9:00 定时触发，首个动作加"条件判断"分支——当前月份为 1/4/7/10 月（可用辅助公式字段 `IF(OR(MONTH(TODAY())=1, MONTH(TODAY())=4, MONTH(TODAY())=7, MONTH(TODAY())=10), "季度月", "非季度月")` 或在条件中判断）才继续执行汇总动作，其余月份自动结束；
  - **手动/日历驱动**：用飞书日历每季度创建提醒，由人工点击运行自动化或由智能体对话触发汇总。
- **条件**：评定周期 = 当前季度
- **动作**：
  1. 汇总各供应商的质量、交付、服务、价格得分
  2. 计算加权总分和等级
  3. 生成季度绩效报告
  4. 通知采购负责人审核
### 2.8 降本到期提醒（定时触发）
- **触发器**：定时触发，每周一 9:00
- **条件**：降本追踪表中"有效期限" ≤ 今天 + 30 天
- **动作**：
  1. 通知责任人：降本价格即将到期，需重新谈判
  2. 更新降本追踪状态为"即将到期"
### 2.9 供应商变更管理（新增记录触发）
- **触发器**：供应商档案表"合作状态"或"供应商等级"字段变更时
- **动作**：
  1. 等级发生变化 → 自动记录到变更日志
  2. 状态变为"淘汰" → 通知技术服务部从合格名录移除
  3. 状态变为"暂停" → 通知采购部暂停新订单，通知财务暂停付款
  4. 等级提升（如 C→B）→ 通知采购部调整份额策略
### 2.10 风险预警自动升级（定时触发）
- **触发器**：定时触发，每周一 9:00
- **条件**：风险评估矩阵中 RPN ≥ 80 或 依赖度预警 = "🔴 过度依赖"
- **动作**：
  1. 通知风险负责人和采购负责人
  2. 自动创建跟进任务
  3. 更新风险状态为"监控中"
  4. 生成风险周报（RPN TOP 10 清单）
### 2.11 合规检查定期提醒（定时触发）
- **触发器**：定时触发，每月 1 日 9:00
- **条件**：合规检查表中"整改状态" ≠ "已关闭"
- **动作**：
  1. 通知检查人和复核人
  2. 逾期未整改（整改截止日期 < 今天）自动升级为高风险
  3. 通知部门负责人
### 2.12 品类策略复盘提醒（定时触发）
- **触发器**：定时触发，每半年 1 月/7 月 1 日 9:00
- **飞书变通方案**：同 2.7，定时触发无"每半年"选项。落地方式二选一：
  - **每月触发 + 半年月判断**：设每月 1 日 9:00 定时触发 + 条件判断当前月份为 1 月或 7 月才执行（辅助公式字段 `IF(OR(MONTH(TODAY())=1, MONTH(TODAY())=7), "复盘月", "非复盘月")`）；
  - **"到达记录中的时间时"触发**：以品类策略管理表「下次复盘日期」为触发时间字段，配置"当到达记录中的时间时"触发器，每条品类记录到期自动提醒（推荐，无需判断月份，复盘后更新下次复盘日期即可循环）。
- **条件**：品类策略管理表中"下次复盘日期" ≤ 今天
- **动作**：
  1. 通知品类负责人
  2. 自动汇总该品类关键指标（降本率、准时交付率、合格率）
  3. 生成品类策略复盘报告

角色：你是供应链风险管理专家，持续监控供应商和供应链的潜在风险，主动发出预警。你像一位警觉的哨兵，在风险演变为危机之前提前预警。
能力：
- 监控供应商风险指标变化（绩效下降、财务异常、交付延迟趋势）
- 识别单一依赖风险（HHI 指数变化、供应商集中度）
- 追踪风险评估矩阵中 RPN 值变化趋势
- 生成风险周报/月报
- 提供风险应对建议
输出规则：
- 风险预警按等级排序：🔴高 > 🟡中 > 🟢低
- 每条预警包含：风险类型、关联供应商/物料、当前值、变化趋势、建议行动
- 新增风险标"🆕"，升级风险标"⬆️"
- 风险周报包含：风险全景图、TOP 5 风险、本周变化、行动建议
禁止行为：
- 不得自动暂停供应商合作（仅建议）
- 不得修改风险评估矩阵中的 RPN 值（仅建议评估）
- 不得忽略低风险的累积效应
```
**工具权限**：风险评估矩阵读写、供应商档案表只读、采购订单台账只读、绩效评定表只读、消息发送
**触发器**：
- 定时触发（每周一 9:00 生成风险周报）
- 记录触发（RPN≥80 的新风险记录自动通知）
- 对话触发（按需查询风险状态）
**实际对话示例**：
| 用户输入 | 智能体响应逻辑 |
|---------|--------------|
| "哪些供应商存在单一依赖风险？" | 查询风险评估矩阵，筛选依赖度预警=🔴过度依赖，输出供应商、品类、依赖度、备选情况 |
| "最近3个月RPN最高的风险有哪些？" | 查询风险矩阵，按RPN降序排列TOP10，标注趋势（上升/下降/持平） |
| "生成这周的风险周报" | 汇总本周风险变化：新增风险、升级风险、关闭风险、RPN TOP5、行动建议 |
| "XX供应商最近有什么风险？" | 查询与该供应商相关的所有风险记录，按风险等级排序，输出风险清单和状态 |
| "我们的进口原料有什么地缘风险？" | 筛选风险类别=地缘政治，关联进口物料，输出受影响物料清单和备选方案 |

## 5. 仪表盘设计建议
### 采购管理驾驶舱（高管视角）
- **KPI 卡片**：本月采购总额 / 供应商总数 / 合同到期数 / 异常待处理数
- **图表**：
  - 月度采购金额趋势（折线图）
  - ABC 分类占比（饼图）
  - 供应商等级分布（柱状图）
  - 卡拉杰克矩阵分布（四象限散点图）
- **预警区**：即将到期合同清单、低库存物料清单
### 采购运营看板（执行层视角）
- **KPI 卡片**：待处理订单 / 本周到货 / 异常待关闭 / 对账差异数
- **图表**：
  - 订单状态分布（看板/饼图）
  - 到货准时率趋势（折线图）
  - 供应商绩效排名（横向柱状图）
  - 对账差异趋势（柱状图）
- **列表区**：我的待办任务、待审批请购单
### PMP 项目进度看板
- **KPI 卡片**：进行中项目数 / 平均 SPI / 延期项目数 / 高风险数
- **图表**：
  - 项目状态分布（饼图）
  - SPI 分布（散点图/柱状图）
  - 甘特图（项目时间线）
  - 风险等级分布（堆叠柱状图）
### 降本增效看板
- **KPI 卡片**：年度累计节约额 / 降本项目数 / 健康降本占比 / 即将到期降本数
- **图表**：
  - 降本类型分布（饼图：价格谈判/替代物料/工艺优化等）
  - 月度节约额趋势（柱状图）
  - 供应商降本贡献排名（横向柱状图）
  - 降本率分布（直方图）
- **预警区**：30天内到期降本清单、降本异常（质量/交付受影响）
### ESG 可持续采购看板
- **KPI 卡片**：ESG 评估覆盖率 / A 级供应商占比 / 平均碳排放 / 合规风险数
- **图表**：
  - ESG 等级分布（饼图）
  - E/S/G 三维雷达图
  - 碳排放趋势（折线图）
  - 供应商环保认证覆盖率（柱状图）
- **预警区**：D 级供应商清单、合规风险供应商
### 供应链风险管理看板
- **KPI 卡片**：高风险数（RPN≥80）/ 过度依赖供应商数 / 本月新增风险 / 已关闭风险
- **图表**：
  - 风险等级分布（饼图：高/中/低）
  - RPN 趋势（折线图，月度）
  - 风险类别分布（柱状图：断供/价格/质量/地缘政治等）
  - 单一依赖度 TOP 10（横向柱状图）
- **预警区**：RPN TOP 10 清单、过度依赖供应商清单、价格波动异常清单
### 品类策略管理看板
- **KPI 卡片**：品类总数 / 战略品类数 / 策略匹配率 / 待复盘品类数
- **图表**：
  - 四象限分布（散点图：支出金额 × 风险等级）
  - 品类策略分布（饼图：战略合作/竞价招标/框架协议等）
  - 降本目标 vs 实际（柱状图，按品类）
  - 供应商份额分配（堆叠柱状图，按品类）
- **预警区**：待复盘品类清单、策略不匹配品类、供应商数量异常品类
### 采购人员能力看板
- **KPI 卡片**：团队平均分 / 资深人数 / 待提升人数 / 培训中人数
- **图表**：
  - 能力等级分布（饼图：资深/熟练/合格/待提升）
  - 四维能力雷达图（团队平均：谈判/品类知识/数据分析/合规意识）
  - 个人能力矩阵（散点图：X=品类知识, Y=谈判能力，气泡大小=数据分析）
  - 培训达标率趋势（折线图）
- **预警区**：待提升人员清单、培训逾期人员、薄弱维度分析

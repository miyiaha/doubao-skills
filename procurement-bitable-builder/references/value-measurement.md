# 价值自测与效果量化清单
> 适用场景：很多用户搭建完系统后"感觉不出价值提升"。本文档提供一套**可操作的自测机制**，让你在搭建前后分别做一次测量，用可量化的数据对比（时间节省、质量提升、成本管控、风险防控等），亲眼看到这套采购管理系统的真实价值，并形成持续复盘的反馈闭环。

## 1. 为什么需要价值自测
采购管理系统常见的"价值感知缺失"问题：
- ❌ 系统搭好了，但**没记录搭建前的基线数据**，无从对比
- ❌ 只关注"表搭了多少张"，没关注"业务效率提升多少"
- ❌ 没有固定频率的复盘，价值随时间衰减无人发现
- ❌ 领导问"这套系统带来什么价值"时答不上来
**自测的价值**：把"感觉有用"变成"数据证明有用"——既向老板证明投入产出（ROI），也帮你持续发现系统哪里没用好、哪里还能优化。
> 💡 核心原则：**搭建前先测基线 → 搭建后按时复测 → 数据差异即价值证明**。

## 2. 搭建前后对比评估维度
### 2.1 六个核心评估维度
| 维度 | 关注点 | 搭建前（Excel/手工）的典型状态 | 搭建后（多维表格）应达到的目标 |
|------|--------|------------------------------|------------------------------|
| **时间节省** | 台账维护、查询、汇总、报告生成耗时 | 手工录台账、逐表复制汇总，月报半天起步 | 查询/汇总即点即得，月报 30 分钟内 |
| **交付质量** | 准时交付率、数据准确性、重复录入率 | 数据靠记忆、口径不统一、重复录入多 | 数据唯一来源，自动化校验，口径统一 |
| **成本管控** | 降本率、价格差异、超预算订单 | 降本靠感觉，无法量化 | 降本追踪表实时核算，偏差自动预警 |
| **风险防控** | 断供、逾期、资质过期、单一依赖 | 靠人盯，漏掉才发现 | 自动化预警提前 30-60 天通知 |
| **协作效率** | 跨部门信息同步、审批时效 | 邮件/微信来回问，进度靠催 | 共享台账实时同步，权限清晰 |
| **决策支撑** | 数据可追溯、报表可复用 | 汇报前临时找数、拼报表 | 仪表盘一键看数，报告模板复用 |
### 2.2 指标口径定义（统一口径才能对比）
| 指标 | 口径说明 | 建议测量方式 |
|------|---------|-------------|
| 台账维护耗时（小时/周） | 每周录入+维护各台账的累计工时 | 团队成员估算 + 抽样记录 |
| 数据查询耗时（分钟/次） | 找一条供应商/订单历史记录的时间 | 实测取 3 次平均值 |
| 月度报告耗时（小时/月） | 从收集数据到报告成稿 | 记录一次完整过程 |
| 降本率（%） | `(原单价-现单价)/原单价×100` | 从降本追踪表公式自动得出 |
| 准时交付率（%） | 准时到货订单/总订单 | 从到货明细表统计 |
| 来料合格率（%） | 合格数量/到货数量 | 从到货质检字段统计 |
| 合同到期遗漏数（次/季度） | 因无人提醒导致到期未处理 | 记录遗漏事件 |
| 库存断供次数（次/季度） | 因库存预警不及时导致断供 | 记录断供事件 |
| 对账差异处理时长（天） | 从发现差异到核清 | 记录差异台账 |
> 搭建前用 Excel 手算或估一个基线值，搭建后用系统内公式/仪表盘自动读取，两者对比即价值。

## 3. 五分钟快速自测（搭建当天做）
> 目的：建立"搭建前基线"，并为后续复测留存依据。建议搭建前或搭建当天 5 分钟内完成。
### 3.1 基线记录表（搭建前/当天填写）
| 问题 | 你的答案（基线值） |
|------|------------------|
| 1. 目前管理几家供应商？用什么工具？ | |
| 2. 每周花多少小时维护台账？ | |
| 3. 查一条历史订单记录平均要多久？ | |
| 4. 最近一次合同到期没人提醒是什么时候？ | |
| 5. 上一季度有没有因库存不足断过供？几次？ | |
| 6. 上一季度降本率是多少？有数据吗？ | |
| 7. 月度采购报告从收集数据到完成要多久？ | |
| 8. 供应商绩效评估有统一口径吗？评估一次要多久？ | |
| 9. 跨部门要数据一般要催几次、等多久？ | |
| 10. 给老板汇报时，数据是现查的还是现成的？ | |
> 把这 10 个答案存进一个「价值自测记录」表（可直接用一张 Excel/多维表格保存），这就是你的对比基线。
### 3.2 搭建完成即检项（当天验证系统是否"跑通"）
| 检查项 | ✅ 标准 | 通过 |
|--------|--------|------|
| 核心表已建且字段完整 | 供应商/订单/合同/到货/对账 5 张以上 | ☐ |
| 关键公式已生效 | TCO、加权分、到期倒计时、预警状态能算出值 | ☐ |
| 关联字段已打通 | 订单能跳到对应供应商 | ☐ |
| 至少 1 条自动化已配置并测试 | 测试触发一次能收到通知 | ☐ |
| 仪表盘/看板已建立 | 打开能看到核心 KPI | ☐ |

## 4. 两周后深度自测清单
> 目的：系统正式投入使用两周后，做一次完整对比，形成第一份"价值证明"。每项都对比第 3.1 节的基线。
### 4.1 效率类自测
| 自测问题 | 对比方式 | 判断标准 |
|---------|---------|---------|
| 台账维护耗时下降了多少？ | 复测周耗时 vs 基线 | 下降 ≥30% 为显著 |
| 查一条记录现在要多久？ | 实测 3 次取平均 vs 基线 | 从"分钟级"降到"秒级" |
| 月度报告还需要手动汇总吗？ | 能否直接从仪表盘取数 | 能直接取数为达标 |
| 重复录入是否明显减少？ | 对比录入同一数据的次数 | 数据唯一来源为达标 |
### 4.2 质量与成本类自测
| 自测问题 | 数据来源 | 判断标准 |
|---------|---------|---------|
| 准时交付率当前是多少？ | 到货明细表统计 | 对比行业基准（见 benchmarks.md） |
| 来料合格率当前是多少？ | 到货质检字段 | 对照目标值 |
| 已记录多少条降本措施、节约多少？ | 降本追踪表 | 有数据记录即有效 |
| 是否发现超预算/价格异常订单？ | 采购订单表+预警 | 能被自动标记为达标 |
| 供应商绩效有统一评分了吗？ | 绩效评定表 | 全部供应商都有评分为达标 |
### 4.3 风险防控类自测
| 自测问题 | 数据来源 | 判断标准 |
|---------|---------|---------|
| 合同/资质到期是否被自动提醒？ | 自动化通知记录 | 有提醒记录即达标 |
| 有没有因系统提前预警而避免的断供/逾期？ | 记录 1-2 个实例 | 有实例即为显著价值 |
| 高风险供应商（RPN≥80）是否被识别？ | 风险评估矩阵表 | 有 TOP 清单为达标 |
| 库存低/超储是否有预警？ | 库存预警表 | 预警准确触发为达标 |
### 4.4 协作与决策类自测
| 自测问题 | 对比方式 | 判断标准 |
|---------|---------|---------|
| 跨部门取数据还需要反复催吗？ | 对比催办次数 | 显著减少为达标 |
| 汇报数据是现查还是现成？ | 打开仪表盘能否直接讲 | 能直接讲为达标 |
| 报告产出速度提升多少？ | 对比报告模板复用情况 | 套模板 30 分钟完成为达标 |

## 5. 月度价值测算表
> 每月底用 10 分钟填一次，形成"价值变化趋势"数据，用于向管理层汇报 ROI。
### 5.1 价值测算表模板（每月填写）
| 指标 | 基线值（搭建前） | 本月值 | 变化 | 折算说明 |
|------|----------------|--------|------|---------|
| 台账维护耗时（小时/周） | | | | 折算人力成本 = 小时×团队时薪 |
| 月度报告耗时（小时/月） | | | | 折算人力成本 |
| 降本率（%） | | | | 直接折算年化节约额 |
| 年化节约额（元/年） | | | | =（原单价-现单价）×年采购量 |
| 准时交付率（%） | | | | 提升 1%≈减少缺料损失 |
| 合同到期遗漏（次/季） | | | | 每次遗漏≈违约/续约损失 |
| 断供次数（次/季） | | | | 每次断供≈停产损失 |
| 对账差异处理时长（天） | | | | 折算财务人效 |
### 5.2 简单 ROI 计算
```
投入成本（元）= 搭建工时 * 时薪 + 平台/套餐费用
年化收益（元）= Σ(各项节省折算：人力 + 降本 + 避免损失)
投资回报率 ROI = (年化收益 - 投入成本) / 投入成本 * 100
```
> 💡 ROI 结果为 0-100 数字口径（如 150 代表 150%），与全包公式口径一致。
> 💡 示例口径：某企业周维护 6 小时→1 小时，省 5 小时/周 × 50 元/时 × 52 周 ≈ 1.3 万/年；降本率 3%×年采购额 500 万 ≈ 15 万/年；避免 1 次断供损失 ≈ 5 万。仅这几项年化收益即超 20 万，远高于搭建投入。
> ⚠️ 数字仅作量级参考，请用自己企业真实数据代入（复杂乘法用 Excel/表格公式自动算，避免手算误差）。

## 6. 效果反馈机制与复盘建议
### 6.1 反馈采集机制（三通道）
| 通道 | 方式 | 频率 | 产出 |
|------|------|------|------|
| 系统数据 | 仪表盘 KPI、自动化触发记录、预警日志 | 实时/自动 | 客观指标 |
| 用户反馈 | 每月一次团队问卷（10 题，见下） | 每月 | 主观满意度 |
| 人工记录 | 价值事件登记（"因系统避免了 XX"） | 随时 | 案例证据 |
### 6.2 月度团队反馈问卷（可直接复制使用）
```
1. 这套系统让你的日常工作效率提升了吗？（1-10 分）
2. 找数据/做报表比之前快了多少？（1-10 分）
3. 预警提醒有没有帮你避免错过重要事项？（是/否，举例）
4. 哪个功能最有用？（多选：关联/公式/自动化/仪表盘/智能体）
5. 哪个环节最不好用/最耗时？
6. 有没有因为你不会用而绕开系统的场景？
7. 你希望下个月优先优化什么？
8. 平均每周因为这套系统节省了多少小时？
9. 你实际使用这套系统的频率是？（每天 / 每周几次 / 偶尔 / 基本不用）
10. 总体而言你愿意把这套系统推荐给其他部门吗？（0-10 分 NPS）
```
### 6.3 复盘节奏建议
| 节奏 | 做什么 | 谁来做 |
|------|--------|--------|
| 每周 10 分钟 | 看预警触发记录，确认无遗漏、无误报 | 系统管理员/采购经理 |
| 每月 30 分钟 | 填价值测算表 + 团队问卷回收 + 对比上月趋势 | 采购经理 |
| 每季度 1 小时 | 价值复盘会：对照成熟度路线图，确认是否进入下一阶段 | 采购总监 |
| 每半年 1 小时 | 整体体检：是否还有手工环节、公式/自动化是否需要优化 | 采购经理+系统管理员 |
### 6.4 复盘输出模板（季度）
| 板块 | 内容 |
|------|------|
| 价值数据 | 关键指标前后对比（复用第 5.1 表） |
| 案例沉淀 | 2-3 个"系统避免损失/提升效率"的真实故事 |
| 问题清单 | 未达标的指标、用户反馈的低分项 |
| 优化计划 | 下季度要补的表/公式/自动化/培训 |
| 向上汇报 | 一页纸 ROI 结论（投入 vs 收益） |
### 6.5 让价值持续放大的建议
1. **把自测沉淀为团队习惯**：每月固定时间做，不要"搭完就忘"。
2. **数据真实才有效**：基线值如实记录，不要美化，对比才有说服力。
3. **价值案例随手记**：每次"系统帮忙避免了损失/省了时间"都记录，季度汇报时直接引用。
4. **持续迭代而非一次交付**：结合自测结果，按 [quality-checklist.md](quality-checklist.md) 与 [benchmarks.md](benchmarks.md) 不断补齐短板，让系统跟随业务成长。
5. **善用平台能力**：飞书用户可把价值测算表做成仪表盘，让"价值"本身也自动化呈现；非飞书用户用 Excel/在线表格同样可维护这套自测机制。

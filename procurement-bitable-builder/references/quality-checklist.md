## 2. 公式正确性验证
### 2.1 公式验证方法
对每个公式字段执行以下三步验证：
```
步骤 1：语法检查
  - 公式是否无语法错误（无红色标记）
  - 括号是否匹配
  - 字段名是否正确引用
步骤 2：逻辑验证
  - 手动计算一条记录的预期结果
  - 与公式自动计算结果对比
  - 确认逻辑正确
步骤 3：边界测试
  - 测试空值情况（分母为 0、日期为空等）
  - 测试极端值（极大金额、极小数量）
  - 确认无异常返回
```

### 2.3 公式问题排查流程
```
公式异常 → 检查语法 → 检查字段引用 → 检查数据类型 → 检查边界条件
  │
  ├── 语法错误 → 检查括号匹配、逗号/分号、函数名拼写
  ├── 字段引用错误 → 确认字段名与表内完全一致
  ├── 数据类型不匹配 → 确认参与计算的字段是数字类型
  ├── 除零错误 → 添加 IF 判断分母是否为 0
  └── 空值传播 → 添加 IF 判断关键字段是否为空
```

## 3. 自动化触发器测试用例
### 3.1 逐条自动化测试
对每条自动化触发器执行以下测试：
| 序号 | 自动化名称 | 触发器类型 | 测试方法 | 预期结果 | 通过 |
|------|-----------|-----------|---------|---------|------|
| 1 | 合同到期预警 | 定时（每日） | 创建一条到期日=今天+30 的合同 | 收到预警通知 | ☐ |
| 2 | 库存预警 | 记录修改 | 将某物料当前库存改为低于安全库存 | 收到预警+自动生成请购单 | ☐ |
| 3 | 到货异常通知 | 新增记录 | 新增一条"质量不合格"异常 | 采购员和质量部收到通知 | ☐ |
| 4 | 对账差异提醒 | 字段修改 | 修改发票金额使差额≠0 | 经办人收到核查通知 | ☐ |
| 5 | 供应商资质到期 | 定时（每周） | 设置有效期至=今天+20 天 | 收到资质到期提醒 | ☐ |
| 6 | 订单状态流转 | 字段修改 | 将订单状态改为"已完成" | 自动关联到对账台账 | ☐ |
| 7 | 绩效自动汇总 | 定时（每季） | 等待季度末触发 | 自动计算加权总分和等级 | ☐ |
| 8 | 降本到期提醒 | 定时（每周） | 设置有效期限=今天+15 天 | 收到降本到期提醒 | ☐ |
| 9 | 供应商变更管理 | 字段修改 | 将供应商等级从 B 改为 A | 等级变更记录+通知 | ☐ |
| 10 | 风险预警升级 | 定时（每周） | 创建 RPN≥80 的风险记录 | 收到风险预警+创建跟进任务 | ☐ |
| 11 | 合规检查提醒 | 定时（每月） | 存在整改状态≠已关闭的记录 | 收到合规检查提醒 | ☐ |
| 12 | 品类策略复盘 | 定时（每半年） | 设置下次复盘日期≤今天 | 收到复盘提醒+品类汇总数据 | ☐ |
> 💡 频率变通：飞书自动化定时触发器原生仅支持每天/每周/每月等固定频率，无"每季度/每半年"选项。变通做法：①用「每月」触发 + 条件分支判断当前月份（仅 1/4/7/10 月或 1/7 月执行通知）；②或改用「当到达记录中的时间时」触发器，按每条记录的下次评估/复盘日期逐条提醒（推荐，见 formulas-automations.md 2.7/2.12）。测试时按实际采用的方案验证。

## 4. 权限配置检查
### 4.1 表级权限
| 检查项 | 验证方法 | 通过标准 |
|--------|---------|---------|
| 数据源表限制编辑 | 检查"勿动"标记表的权限 | 仅管理员可编辑 |
| 业务表按角色分配 | 检查各表的编辑/查看权限 | 采购部编辑订单，质量部编辑质检字段 |
| 敏感字段限制 | 检查银行账号等字段权限 | 通过"高级权限"配置或用 4.2 视图方案变通，敏感数据不向无关角色暴露 |
| 历史数据只读 | 检查标记"历史"的数据权限 | 所有人只读 |
### 4.2 字段级权限（变通方案）
> ⚠️ 前提说明：飞书多维表格的基础版面通常无法直接对单个字段设置"仅某些人可见/可编辑"的字段级权限（该能力依赖特定版本的高级权限）。若你的版本不支持字段级权限，按下述变通方案落地，验收时按变通方案逐项检查：
**方案 A：视图隐藏字段（推荐）**
| 检查项 | 验证方法 | 通过标准 |
|--------|---------|---------|
| 敏感字段在通用视图中隐藏 | 检查各共享视图的字段显隐配置 | 银行账号、成本价等敏感字段已隐藏 |
| 敏感数据专用视图 | 为财务/管理层单独建视图展示敏感字段 | 该视图仅对授权人员开放 |
| 视图不通过链接外泄 | 检查视图共享方式 | 不开启"组织外可访问"的公开分享 |
**方案 B：自动化提醒兜底**
| 检查项 | 验证方法 | 通过标准 |
|--------|---------|---------|
| 敏感字段变更提醒 | 配置自动化：敏感字段被修改时通知管理员 | 变更可被追溯发现 |
| 敏感表访问审计提醒 | 定期（每月）由管理员人工抽查访问记录 | 有抽查记录 |
| 替代性提示 | 在敏感字段前的字段名或描述中标注"敏感" | 提醒录入者与查看者注意 |
| 其他检查项 | 验证方法 | 通过标准 |
|--------|---------|---------|
| 公式字段不可编辑 | 检查公式字段的编辑权限 | 所有角色只读 |
| 自动编号不可修改 | 检查自动编号字段 | 系统自动生成，不可手动修改 |
| 关键状态字段限制 | 检查订单状态等字段的编辑权限 | 仅指定角色可修改 |
| 金额字段审批后锁定 | 检查已审批记录的金额字段 | 已审批后不可修改（可用锁定记录功能） |
### 4.3 视图权限
| 检查项 | 验证方法 | 通过标准 |
|--------|---------|---------|
| 敏感视图限制访问 | 检查含敏感数据的视图权限 | 仅管理层可见 |
| 仪表盘权限 | 检查各角色仪表盘的访问权限 | 按角色分配 |
| 共享设置 | 检查多维表格的共享范围 | 仅相关人员可访问 |

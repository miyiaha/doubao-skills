# 采购管理多维表格 — 核心表结构模板
本文件包含采购管理场景常用数据表模板。根据业务需要选择并组合使用。
> 📌 **表数量口径说明**：本模板共 **23 类标准表**（对应下方 23 个编号），其中第 6 类「到货明细与异常台账」和第 10 类「采购进度管理表（PMP）」各含 2 张子表（6a/6b、10a/10b），因此**实际物理表为 25 张**。case-studies.md、data-migration.md 中的表清单均按此口径对齐。

| 质量得分（满分 100） | 数字 | 来料合格率、退货率等 |
| 交付得分（满分 100） | 数字 | 准时交付率、数量达成率 |
| 服务得分（满分 100） | 数字 | 响应速度、问题解决效率 |
| 价格得分（满分 100） | 数字 | 价格竞争力、年度降本 |
| 加权总分 | 公式 | 按权重计算 |
| 评定等级 | 公式 | S/A/B/C/D 根据分数区间（见 formulas-automations.md 1.4 等级判定公式） |
| 改进建议 | 多行文本 | — |
| 评定人 | 人员 | — |
| 评定日期 | 日期 | — |
**评分权重参考**：质量 35% / 交付 25% / 服务 20% / 价格 20%（可按品类调整）
**绩效评定等级映射（分数口径，本表「评定等级」字段用，见 formulas-automations.md 1.4）**：
- S 级（评定）：加权总分 ≥90，全面优秀，深度合作
- A 级（评定）：加权总分 80-89，表现良好，框架合作
- B 级（评定）：加权总分 70-79，合格，设定改进目标
- C 级（评定）：加权总分 60-69，备选，限期整改
- D 级（评定）：加权总分 <60，或重大质量/断供/商业贿赂，淘汰
> ⚠️ **两套 S/A/B/C/D 等级勿混淆**：本表「评定等级」= 绩效分数口径（按季度加权总分）；供应商档案表「供应商等级」（S战略/A核心/B合格/C备选/D淘汰）= 战略占比口径（按供应占比/物料等级判定，见 SKILL.md 供应商分级体系）。字母相同但判定依据不同、各自独立计算。

## 视图建议
每张表建议创建以下视图：
- **全量视图**：默认表格视图，展示所有字段
- **看板视图**：按状态字段分组（如订单状态、处理状态）
- **甘特图视图**：适用于有日期区间的表（合同管理、采购进度）
- **画廊视图**：适用于供应商档案（展示附件中的证照）
- **日历视图**：适用于到期日期密集的表（合同到期、付款到期）
- **筛选视图**：按业务维度过滤（如"即将到期合同"="到期日期 ≤ 今天+60 天"）

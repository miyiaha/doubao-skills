# 采购管理多维表格搭建 — 行业定制指南
> 适用场景：本技能提供通用采购管理框架。不同行业（化妆品 OEM、电子制造、食品饮料、医疗器械、通用贸易等）在供应商管理、质量要求、合规重点、成本结构上差异显著。本文档帮助你根据所在行业，对通用模板做**最小化但高价值的定制调整**，让系统真正贴合业务。

## 1. 行业定制总览
### 1.1 各行业核心差异速查
| 维度 | 化妆品 OEM | 电子制造 | 食品饮料 | 医疗器械 | 通用贸易 |
|------|-----------|---------|---------|---------|---------|
| 核心采购品类 | 原料+包材+代工 | 电子元器件+结构件 | 原料+包装 | 原材料+零部件 | 成品+耗材 |
| 质量优先级 | 极高（消费者安全） | 高（功能可靠性） | 极高（食品安全） | 极高（法规强制） | 中 |
| 合规要求 | 备案/功效宣称 | RoHS/REACH | SC/QS/HACCP | ISO13485/GMP | 较少 |
| 保质期管理 | 强（原料/成品） | 弱 | 强（原料/成品） | 中（部分耗材） | 弱 |
| 供应商数量 | 30-60 家 | 50-200 家 | 20-50 家 | 10-30 家 | 10-50 家 |
| 典型年采购额 | 2000万-2亿 | 5000万-10亿 | 1000万-1亿 | 500万-5000万 | 500万-5000万 |
| 定制化程度 | 高（配方/包材） | 高（规格定制） | 中 | 高（法规定制） | 低（标准品） |
### 1.2 定制原则
1. **最小改动原则**：只改与行业强相关的字段、公式权重、自动化规则，不重建整个系统。
2. **先通用后定制**：先按通用模板搭好基础框架，再叠加行业定制项。
3. **合规优先**：行业强制合规要求（如医疗器械 GMP、食品 SC）必须 100% 覆盖。
4. **数据可追溯**：高风险行业（食品/医疗/化妆品）必须强化批次追溯链路。

## 2. 化妆品 OEM/ODM 行业定制
### 2.1 行业特点
- 原料有保质期，活性成分效价随时间衰减
- 包材定制化程度高（瓶型、泵头、印刷）
- 新品打样→中试→量产流程长，质量波动大
- 合规要求：化妆品备案、功效宣称验证、GMP 生产规范
- 供应商类型：原料商、包材商、代工厂、香精香料商
### 2.2 供应商档案表定制字段
在通用供应商档案表基础上，增加以下行业专属字段：
| 字段名 | 字段类型 | 说明 |
|--------|---------|------|
| 生产许可证号 | 文本 | 化妆品生产许可证编号 |
| GMP 认证状态 | 单选 | 已认证/认证中/未认证 |
| GMP 认证有效期 | 日期 | 到期自动预警 |
| 备案能力 | 多选 | 普通化妆品/特殊化妆品/进口备案 |
| 功效验证能力 | 多选 | 保湿/美白/抗皱/防晒/修护等 |
| 动物实验政策 | 单选 | 不做动物实验/可做/视情况 |
| 冷链存储能力 | 复选框 | 是否具备活性成分冷链存储 |
| 配方保密协议 | 附件 | NDA 扫描件 |
| 主要客户 | 文本 | 参考客户（用于实力评估） |
### 2.3 物料分类表定制
| 定制项 | 说明 |
|--------|------|
| 物料大类增加 | 活性成分/基础原料/香精香料/主包材/辅包材/标签/代工服务 |
| 保质期字段 | 每种物料标注保质期（月），关联库存预警 |
| 存储条件 | 常温/阴凉/冷藏/冷冻，关联仓储管理 |
| 备案状态 | 该原料是否已完成化妆品原料备案 |
| 风险等级 | 高风险（活性成分/防腐剂）/中风险/低风险 |
### 2.4 到货明细表定制
| 定制字段 | 说明 |
|---------|------|
| 批次号 | 原料批次号（追溯必需） |
| COA 编号 | 检验报告编号 |
| COA 附件 | 附件（上传检验报告） |
| 保质期至 | 该批次保质期截止日期 |
| 留样数量 | 留样数量（质量追溯） |
| 留样到期日 | 留样保存截止日期 |
| 微生物检测 | 单选 | 合格/不合格/待检 |
| 重金属检测 | 单选 | 合格/不合格/待检 |
| 功效成分含量 | 数字 | 活性成分实测含量 |
| 是否新品首批 | 复选框 | 标记新品首批，专项质量追踪 |
### 2.5 绩效评定权重定制
化妆品行业质量权重应高于通用标准：
| 维度 | 通用权重 | 化妆品定制权重 | 调整理由 |
|------|---------|--------------|---------|
| 质量 | 35% | **40%** | 直接关系消费者安全 |
| 交付 | 25% | 25% | 不变 |
| 服务 | 20% | 15% | 降低 |
| 价格 | 20% | 10% | 降低，质量优先于价格 |
| 新品配合度 | — | **10%** | OEM 行业特色，打样配合度关键 |
> 落地公式（字段均落在供应商绩效评定表）：
> - **化妆品加权总分** = 质量×0.40 + 交付×0.25 + 服务×0.15 + 价格×0.10 + 新品配合度×0.10
> - **化妆品评定等级** = IF(化妆品加权总分≥90,"S",IF(≥80,"A",IF(≥70,"B",IF(≥60,"C","D"))))
### 2.6 自动化定制
| 自动化 | 定制规则 |
|--------|---------|
| GMP 认证到期预警 | 到期前 90 天提醒（比通用 60 天更早） |
| 原料保质期预警 | 到货时自动计算保质期至，到期前 3 个月预警 |
| 新品首批必检 | 标记"新品首批"的到货自动通知质量部全检 |
| 备案资料到期 | 备案有效期到期前 6 个月提醒续期 |
### 2.7 仪表盘定制
增加「新品质量专项看板」：
- KPI：新品首批合格率、新品打样周期、新品异常关闭率
- 图表：新品合格率趋势（按供应商）、新品异常类型分布
- 列表：待处理新品异常清单

## 3. 电子制造行业定制
### 3.1 行业特点
- 元器件种类多（电阻/电容/IC/连接器等），单价低但数量大
- 质量要求高，不良率以 PPM（百万分之一）计
- 供应链全球化，进口元器件交期长
- 合规：RoHS（有害物质限制）、REACH（化学品注册）
- 供应商数量多（50-200 家），分级管理重要
### 3.2 供应商档案表定制字段
| 字段名 | 字段类型 | 说明 |
|--------|---------|------|
| 代理商/原厂 | 单选 | 原厂/代理商/贸易商 |
| 代理品牌 | 文本 | 代理的元器件品牌 |
| RoHS 合规 | 复选框 | 是否符合 RoHS |
| REACH 合规 | 复选框 | 是否符合 REACH |
| 无铅工艺 | 复选框 | 是否支持无铅焊接 |
| 最小起订量(MOQ) | 数字 | 元器件 MOQ |
| 交期(周) | 数字 | 标准交期 |
| 现货能力 | 单选 | 有现货/需订货/混合 |
| 缺货记录 | 数字 | 历史缺货次数 |
### 3.3 物料分类表定制
| 定制项 | 说明 |
|--------|------|
| 物料大类 | 主动器件/被动器件/结构件/PCB/连接器/线材/辅料 |
| 元器件参数 | 封装/规格/耐压/容值/精度等 |
| 替代料 | 关联可替代的物料 |
| 生命周期 | 量产/停产预警/已停产/EOL |
| 环保等级 | RoHS/REACH 合规状态 |
### 3.4 到货明细表定制
| 定制字段 | 说明 |
|---------|------|
| 来料批次号 | 元器件批次（追溯） |
| 生产日期码 | 芯片生产日期（D/C） |
| 不良数(PPM) | 数字，计算不良率 |
| SMT 上线不良 | 数字，产线反馈不良数 |
| RoHS 检测报告 | 附件 |
| 真伪验证 | 单选 | 正品/疑似假货/待验证 |
### 3.5 绩效评定权重定制
| 维度 | 通用权重 | 电子制造定制权重 |
|------|---------|----------------|
| 质量 | 35% | **40%**（PPM 管理） |
| 交付 | 25% | **30%**（交期敏感） |
| 服务 | 20% | 15% |
| 价格 | 20% | 15% |
### 3.6 自动化定制
| 自动化 | 定制规则 |
|--------|---------|
| 元器件停产预警 | 监测 EOL 通知，自动创建替代料评估任务 |
| 缺货预警 | 交期超过标准交期 1.5 倍时预警 |
| PPM 超标预警 | 单批次 PPM 超过阈值自动通知质量部 |
| 价格波动监控 | 核心元器件价格波动超过 10% 预警 |

## 4. 食品饮料行业定制
### 4.1 行业特点
- 食品安全是红线，SC 认证强制
- 原料保质期严格，先进先出（FIFO）
- 季节性强（农产品原料）
- 供应商相对集中（20-50 家）
- 合规：SC 生产许可、HACCP、ISO22000、食品添加剂使用标准
### 4.2 供应商档案表定制字段
| 字段名 | 字段类型 | 说明 |
|--------|---------|------|
| SC 许可证号 | 文本 | 食品生产许可证 |
| SC 有效期 | 日期 | 到期预警 |
| HACCP 认证 | 复选框 | 危害分析关键控制点 |
| ISO22000 | 复选框 | 食品安全管理体系 |
| 原料产地 | 文本 | 农产品产地（溯源） |
| 农药残留检测 | 附件 | 农残检测报告 |
| 食品添加剂资质 | 复选框 | 是否具备食品添加剂生产资质 |
| 冷链运输能力 | 复选框 | 生鲜/冷链原料 |
### 4.3 物料分类表定制
| 定制项 | 说明 |
|--------|------|
| 物料大类 | 生鲜原料/干货原料/食品添加剂/包装材料/辅料 |
| 保质期 | 严格标注，关联 FIFO 管理 |
| 存储条件 | 常温/冷藏/冷冻/阴凉干燥 |
| 食品添加剂使用范围 | 文本，GB2760 合规 |
| 过敏原标识 | 多选，含麸质/乳制品/坚果等 |
### 4.4 到货明细表定制
| 定制字段 | 说明 |
|---------|------|
| 生产批次 | 原料批次号 |
| 生产日期 | 该批次生产日期 |
| 保质期至 | 严格管理 |
| 农残检测报告 | 附件 |
| 微生物检测 | 单选，合格/不合格/待检 |
| 感官检验 | 单选，合格/不合格/待检（色泽/气味/形态） |
| 温度记录 | 数字，到货时运输温度（冷链） |
| FIFO 状态 | 单选，先进先出/需优先使用 |
### 4.5 自动化定制
| 自动化 | 定制规则 |
|--------|---------|
| SC 证到期预警 | 到期前 90 天提醒续期 |
| 原料保质期预警 | 到期前 1/3 保质期时预警（如 12 个月保质期，到期前 4 个月预警） |
| 冷链断链预警 | 到货温度超出范围自动通知 |
| 添加剂超标预警 | 检测到添加剂使用量超 GB2760 限值自动预警 |

## 5. 医疗器械行业定制
### 5.1 行业特点
- 法规最严格，ISO13485 + GMP 强制
- 供应商审核流程长，准入门槛高
- 可追溯性要求极高（UDI 唯一器械标识）
- 变更控制严格（任何变更需验证）
- 供应商数量少但合作深（10-30 家）
### 5.2 供应商档案表定制字段
| 字段名 | 字段类型 | 说明 |
|--------|---------|------|
| ISO13485 认证 | 复选框 | 医疗器械质量管理体系 |
| ISO13485 有效期 | 日期 | 到期预警 |
| GMP 符合性 | 单选 | 通过/待审核/不通过 |
| 供应商审核报告 | 附件 | 现场审核报告 |
| 审核周期 | 单选 | 年度/半年度/季度 |
| 上次审核日期 | 日期 | |
| 下次审核日期 | 日期 | 自动提醒 |
| 变更控制协议 | 附件 | 供应商变更控制协议（VCA） |
| UDI 支持能力 | 复选框 | 是否支持唯一器械标识 |
| 洁净室等级 | 文本 | ISO 5/6/7/8 |
### 5.3 到货明细表定制
| 定制字段 | 说明 |
|---------|------|
| 批号/序列号 | 严格追溯 |
| UDI 码 | 唯一器械标识 |
| 灭菌批号 | 如适用 |
| 灭菌有效期 | 如适用 |
| 出厂检验报告(COA) | 附件 |
| 生物相容性报告 | 附件（如适用） |
| 无菌检测报告 | 附件（如适用） |
| 接收检验记录 | 附件 |
| 放行状态 | 单选，待检/合格放行/让步接收/拒收 |
### 5.4 自动化定制
| 自动化 | 定制规则 |
|--------|---------|
| 审核到期预警 | 下次审核日期前 60 天提醒安排审核 |
| ISO13485 到期预警 | 到期前 90 天提醒 |
| 供应商变更通知 | 供应商任何变更（工艺/原材料/场地）需提前通知并评估 |
| 不合格品处理 | 到货不合格自动创建 NCR（不合格品报告）流程 |
### 5.5 绩效评定权重定制
| 维度 | 通用权重 | 医疗器械定制权重 |
|------|---------|----------------|
| 质量 | 35% | **50%**（法规强制） |
| 交付 | 25% | 20% |
| 服务 | 20% | 15% |
| 价格 | 20% | 15% |

## 6. 通用贸易/电商行业定制
### 6.1 行业特点
- 以成品采购为主，定制化程度低
- 供应商数量灵活（10-50 家）
| 价格敏感，比价频繁
- 交期要求高（电商发货时效）
- 质量要求中等，退换货管理重要
### 6.2 供应商档案表定制字段
| 字段名 | 字段类型 | 说明 |
|--------|---------|------|
| 一件代发能力 | 复选框 | 是否支持一件代发 |
| 发货时效 | 单选，24h/48h/72h/更长 |
| 退换货政策 | 文本 |
| 最小起订量 | 数字 |
| 现货库存能力 | 单选，充足/一般/需订货 |
| 品牌授权 | 附件 | 品牌授权书 |
| 跨境资质 | 复选框 | 是否支持跨境采购 |
### 6.3 到货明细表定制
| 定制字段 | 说明 |
|---------|------|
| 外观检验 | 单选，合格/不合格/待检 |
| 功能检验 | 单选，合格/不合格/待检 |
| 包装完整性 | 单选，完好/破损/轻微破损 |
| 退换货数量 | 数字 |
| 退换货原因 | 多选，质量问题/发错货/客户原因/其他 |
### 6.4 自动化定制
| 自动化 | 定制规则 |
|--------|---------|
| 发货超时预警 | 超过承诺发货时效自动通知 |
| 退换货率超标 | 单供应商退换货率超过 5% 预警 |
| 库存补货提醒 | 热销品库存低于安全库存自动创建采购单 |
| 价格对比提醒 | 同一商品多家供应商价格差异超过 10% 提醒 |

## 7. 行业定制检查清单
完成行业定制后，逐项确认：
- [ ] 供应商档案表已增加行业专属字段
- [ ] 物料分类已按行业调整大类和属性
- [ ] 到货明细表已增加行业质量检测字段
- [ ] 绩效评定权重已按行业调整
- [ ] 自动化规则已增加行业预警项
- [ ] 合规相关字段（许可证/认证）已设置到期预警
- [ ] 行业特有仪表盘已搭建（如新品质量看板）
- [ ] 数据追溯链路已验证（批次号→供应商→到货→使用）
- [ ] 行业强制合规要求 100% 覆盖

### 公式校验脚本（v2.1.2 新增）
本技能从 v2.1.2 起内置**可执行公式校验**，解决"公式只能靠文档、改一处漏一处"的问题。修改任何公式/表模板后，运行：
```bash
node scripts/verify_formulas.mjs     # 或 bash scripts/test.sh
```
它会自动做三件事：
1. **基线复算**：逐项核对 quality-checklist.md 的基准值（加权总分 82.5、基础预测 86、季节调整 111.8、HHI 3800、RPN 60 等），公式口径一变即报错；
2. **边界测试**：守住 v2.1.2 修复项不回归——预测偏差率除零保护（实际需求=0→0）、预测准确率 MAX 钳制（偏差率>100→0 非负）、谈判达成率档位（=100 判「达成」、>100 才「超预期」）、绩效评定等级 S/A/B/C/D 分数边界（90/80/70/60）；
3. **跨文档一致性**：检查 table-templates.md 与 formulas-automations.md 两处公式写法一致、前置字段（品类阈值/风险等级）已定义、platform-comparison 对照公式完整。
全部通过 exit 0（✅ 逻辑闭环），任一失败 exit 1 并打印失败明细。要求 Node ≥18，零依赖。

## 表结构设计要点
### 字段类型选择原则
- **状态字段** → 单选（不用文本），便于看板视图分组和自动化条件判断
- **人/部门** → 人员字段（不用文本），便于通知和权限控制
- **跨表引用** → 关联字段（不用文本），保持数据一致性
- **金额** → 货币字段，自动格式化
- **日期计算** → 公式字段，不手动填
- **只读汇总** → 公式/查找引用，防止误改
### 命名规范
- 表名：`序号.表名`（如 `1.1物料分类管理台账`、`4.1采购订单台账`）
- 编号字段：业务前缀 + 日期/序号（如 PO-20260811-001、CON-2026-001）
- 数据源表名加 `（勿动）` 标记，防止误操作
### 供应商分级体系（五级）
> ⚠️ **两套 S/A/B/C/D 等级勿混淆（v2.1.2 澄清）**：本节「供应商分级体系」指供应商档案表的「供应商等级」——按供应占比/物料等级判定（战略占比口径）；供应商绩效评定表的「评定等级」按季度加权总分判定（分数口径，见 formulas-automations.md 1.4）。两者字母相同但判定依据不同、各自独立计算，绩效评定表勿用本节占比口径替代分数口径。
采用 S/A/B/C/D 五级评定，评定标准详见 table-templates.md 第 8 节。核心逻辑：
- **S 级（战略）**：独家代工或供公司级 A 类占比 ≥70%
- **A 级（核心）**：供品类级 A 类占比 ≥50%
- **B 级（合格）**：供 B 类物料，季度考核 ≥70 分
- **C 级（备选）**：新供应商考察期 / 考核 60-69 分
- **D 级（淘汰）**：<60 分或重大质量/断供/商业贿赂
### 物料分类体系（三维）
- **ABC 价值分类**：帕累托法则（A=0-80% / B=80-95% / C=95-100%）
- **风险分类**：卡拉杰克矩阵（战略型 / 杠杆型 / 瓶颈型 / 常规型）
- **公司级重点**：占公司总采购额前 20% 的 A 类物料
## 自动化配置要点
配置自动化前先确认飞书多维表格的触发器能力：
| 触发器类型 | 采购场景典型用法 |
|-----------|----------------|
| 记录新增 | 新异常记录 → 通知采购员 |
| 字段修改 | 库存变动 → 触发预警判断 |
| 定时触发 | 每日检查合同到期、库存预警 |
| 当到达记录中的时间时 | 合同"到期日期"到达 → 逐条自动提醒（需表中有日期字段） |
**关键原则**：
- 自动化动作不删数据，只标记状态
- 涉及金额和审批的动作设人工确认节点
- 定时触发频率不超每日一次，避免消息轰炸
## 智能体配置要点
多维智能体 = Prompt 四段式 + 最小权限工具 + 触发器组合 + 知识库
1. **Prompt 四段式**：角色定位 → 可执行能力 → 输出规则 → 禁止行为
2. **最小权限**：只给完成该场景所需的最少表读写权限
3. **触发器组合**：对话触发（手动）+ 定时触发（巡检）+ 记录触发（实时）
4. **知识库**：合同模板、合规条款、供应商分级标准等文档灌入
5 个标准智能体方案（台账管家 / 合同预警 / 对账核对 / 数据分析师 / 风险预警）详见 formulas-automations.md 第 3 节。

## 实战经验要点
### 数据迁移策略（从 Excel 到多维表格）
1. **先清洗再导入**：Excel 数据先统一格式（日期 YYYY-MM-DD、金额去千分位逗号、状态字段标准化）
2. **分批导入**：先导入基础表（供应商档案、物料分类），再导入关联表（订单、合同），最后导入明细表
3. **关联字段重建**：Excel 导入后关联字段会丢失，需在飞书中手动重建关联关系
4. **历史数据保留**：旧数据加"历史"标记，新数据从切换日起走新流程
5. **并行运行 1-2 周**：新旧系统并行，确认数据一致性后再切换
### 常见坑点与解决方案
| 坑点 | 表现 | 解决方案 |
|------|------|---------|
| 关联字段失效 | 删除源表记录后关联字段变空 | 源表记录不删，只标记"已作废" |
| 公式性能瓶颈 | 万行数据后公式计算变慢 | 复杂公式放智能体脚本而非表格公式 |
| 权限混乱 | 跨部门协作时误改数据 | 每张表设"数据源表（勿动）"标记，限制编辑权限 |
| 自动化误触发 | 批量导入时触发大量通知 | 导入前关闭自动化，导入后手动触发一次 |
| 编号重复 | 多人同时新增时编号冲突 | 用「自动编号」字段类型，不用手动输入 |
### 部门协作 SOP
1. **采购部**：维护订单、合同、对账数据，主导供应商评估汇总
2. **质量部**：填写到货质检结论、来料合格率，贡献质量维度评分
3. **仓储部**：维护库存数据、到货明细，触发补货预警
4. **技术服务部**：管理合格供应商名录、资质审核、准入退出
5. **财务部**：维护发票、付款数据，核对应付预测
### 定期维护清单
- **每日**：自动化巡检（合同到期、库存预警、异常待处理）
- **每周**：供应商资质到期检查、订单状态更新
- **每月**：对账结算汇总、降本数据统计
- **每季度**：供应商绩效评定、品类策略复盘
- **每年**：供应商分级全面重评、ESG 年度评估
## SCMP 供应链管理实战要点
### 供应链风险三维评估
SCMP 强调供应链风险管理的三个维度：**发生概率 × 影响程度 × 可检测性**（借鉴 FMEA 方法论）。本技能新增「风险评估矩阵」表，支持：
- 断供风险（单一供应商依赖度 ≥70% 自动标红）
- 价格波动风险（原材料价格月度波动率 >15% 触发预警）
- 地缘政治风险（供应区域风险等级标记）
- 质量风险（来料合格率连续 3 个月下降自动升级）
### 品类策略四分法落地
卡拉杰克矩阵在 SCMP 体系中是品类管理的核心工具。本技能新增「品类策略管理」表，将四象限映射为具体执行动作：
- **战略型**：战略合作 + 联合研发 + 长期合同（3-5 年）+ 双源供应
- **杠杆型**：竞价招标 + 框架协议 + 年度降本指标 + 电子竞标
- **瓶颈型**：安全库存 + 替代方案 + 供应商开发 + 技术降本
- **常规型**：系统自动下单 + 框架协议 + 减少供应商数量 + 流程优化
### 需求预测与 S&OP
基于 SCOR 模型的计划（Plan）模块，新增「需求预测」表：
- 历史数据滚动 12 个月加权（近 3 月权重 50%，3-6 月 30%，6-12 月 20%）
- 季节因子调整（OEM 代工旺季/淡季）
- 预测准确率追踪（实际 vs 预测偏差率）
- 安全库存动态计算（基于需求波动和提前期）
### 供应商协同创新
SCMP 强调供应商早期介入（ESI）对 OEM 新品质量的关键作用：
- 联合研发打样进度追踪
- 技术攻关问题闭环
- 供应商创新贡献度量化（降本/提质/增效）
## CPPM 采购专业实战要点
### 谈判管理结构化
CPPM 将谈判分为准备-开局-磋商-成交-复盘五个阶段：
- **谈判前**：BATNA（最佳替代方案）、目标价、底线价、筹码清单
- **谈判中**：多轮出价记录、让步轨迹、关键条款变动
- **谈判后**：达成率分析、vs BATNA 差距、经验沉淀
### 合规三道防线
CPPM 强调采购合规的「三道防线」模型：
1. **第一道（采购部自查）**：利益冲突申报、关联交易审查、围标串标预警
2. **第二道（合规/风控部门）**：定期抽查、合规审计、举报处理
3. **第三道（内部审计）**：年度审计、离任审计、专项审计
本技能新增「合规检查」表，覆盖第一道防线核心检查项，支持自动化预警。
### 采购人员能力矩阵
CPPM 将采购人员能力分为四个维度：
- **谈判能力**：策略制定、BATNA 分析、跨文化谈判
- **品类知识**：行业认知、技术理解、成本构成分析
- **数据分析**：价格趋势、成本建模、TCO 分析
- **合规意识**：法规理解、风险识别、流程规范
新增「人员能力评估」表，支持团队能力盘点、培训需求识别和晋升参考。

## 常见问题 FAQ
### 搭建相关
**Q1：23 张表都需要搭建吗？**
A：不需要。根据你的业务阶段和需求选择。采购新手先搭 5 张核心表，采购经理搭 12 张，采购总监再考虑全部 23 类（含 10 号表拆分的 10a/10b，物理表共 25 张）。参考上方"按角色推荐的搭建方案"。
**Q2：表与表之间的关联字段怎么设置？**
A：先创建所有表 → 再按"表间关联关系图"逐一设置关联字段。注意：导入数据后关联字段会失效，需要重建。
**Q3：公式字段计算错误怎么办？**
A：检查三点：①字段名是否与表内完全一致；②参与计算的字段是否为数字类型（非文本）；③是否有除零或空值情况。参考 [quality-checklist.md](references/quality-checklist.md) 第 2 节。
**Q4：已有的 Excel 数据怎么迁移？**
A：参考 [data-migration.md](references/data-migration.md)，按"数据盘点→清洗→映射→导入→校验"五步法执行。关键：导入前先关闭自动化！
### 使用相关
**Q5：多人同时使用会不会冲突？**
A：飞书多维表格支持多人协作，但需要注意权限配置。建议：数据源表仅管理员可编辑，业务表按角色分配编辑权限。
**Q6：自动化通知太多了怎么办？**
A：①检查是否有不必要的自动化；②定时触发的频率不要太高（建议每日最多一次）；③批量导入前关闭自动化。
**Q7：智能体怎么配置？**
A：参考 [formulas-automations.md](references/formulas-automations.md) 第 3 节。核心四段式：角色定位 → 可执行能力 → 输出规则 → 禁止行为。
### 业务相关
**Q8：供应商绩效评分权重怎么定？**
A：标准权重：质量35%/交付25%/服务20%/价格20%。化妆品OEM建议提高质量权重到40%。按企业实际优先级调整。
**Q9：Should Cost 模型怎么用？**
A：在谈判前，将供应商报价拆解为原材料+加工+包装+物流+管理+利润，与估算的 Should Cost 总价对比，偏差>10%就有议价空间。参考 [formulas-automations.md](references/formulas-automations.md) 第 1.13 节。
**Q10：行业基准数据怎么用？**
A：先用基准数据设定 KPI 目标（如准时交付率目标≥95%），然后在仪表盘中设置参考线，持续追踪实际值与基准的差距。参考 [benchmarks.md](references/benchmarks.md)。

## 错误处理与排错指南
### 公式报错处理
| 错误类型 | 含义 | 排查步骤 | 解决方案 |
|---------|------|---------|---------|
| `#DIV/0!` | 分母为0或空 | 检查除法公式的分母字段 | 用 IF 包裹：`IF(分母>0, 分子/分母, 0)` |
| `#VALUE!` | 字段类型不匹配 | 检查参与计算的字段是否为数字类型 | 确认字段类型：文本型数字需先用 VALUE 转换或用 IF 判断 |
| `#REF!` | 引用的字段/表不存在 | 检查字段名是否被修改或删除 | 恢复字段名或更新公式中的引用 |
| `#NAME?` | 函数名拼写错误 | 检查函数名是否正确 | 参照函数列表修正拼写 |
| 结果为空 | 引用的字段值为空 | 检查关联字段是否正确关联 | 确保关联字段有值，用 IF 判断空值 |
**通用排查流程**：
```
公式报错 → ①点击公式字段查看公式 → ②逐段检查语法 → ③检查引用的字段名和类型 → ④用具体数值手动代入验证
```
### 自动化不触发
| 症状 | 可能原因 | 检查方法 |
|------|---------|---------|
| 完全不触发 | 自动化被关闭 | 检查自动化开关是否开启 |
| 偶尔不触发 | 触发条件过于严格 | 检查条件是否包含所有可能场景 |
| 导入时误触发 | 批量导入前未关闭自动化 | 导入前关闭，导入后再开启 |
| 触发器类型不对 | 用了"记录新增"但实际是"字段修改" | 确认操作类型匹配触发器类型 |
| 通知没收到 | 接收人不在飞书或权限不足 | 确认接收人是飞书用户且有权限 |
### 关联字段异常
| 症状 | 原因 | 解决方案 |
|------|------|---------|
| 导入后关联变文本 | 关联字段不支持 Excel 直接导入 | 先导入为文本 → 所有基础表导入完 → 手动转为关联字段 |
| 点击关联无法跳转 | 目标记录被删除 | 源记录不要删除，改为标记"已作废" |
| 跨套件关联失效 | 飞书多维表格不支持跨套件关联 | 改用"查找引用"或手动维护关联关系 |
| 关联字段显示为空 | 目标表中的关联值不匹配 | 检查关联字段的值是否与目标表的主键完全一致 |
### 权限问题
| 症状 | 解决方案 |
|------|---------|
| 协作者看不到某些表 | 多维表格共享设置 → 添加协作者 → 勾选对应的数据表 |
| 协作者无法编辑 | 检查权限是否为"可编辑"而非"可查看" |
| 想限制某些字段不可编辑 | 目前飞书不支持字段级权限，建议：①用视图隐藏敏感字段；②用自动化锁定 |
| 外部人员需要查看 | 使用"分享链接"功能，设置密码和有效期 |

## 数据解读指南
### 供应商绩效评分解读
| 等级 | 分数范围 | 含义 | 管理动作 |
|------|---------|------|---------|
| S 级 | ≥90 | 战略级，全面优秀 | 深度合作，联合研发，优先份额 |
| A 级 | 80-89 | 核心级，表现良好 | 框架协议，稳定合作，适度增量 |
| B 级 | 70-79 | 合格级，有改进空间 | 指出薄弱环节，设定改进目标 |
| C 级 | 60-69 | 备选级，需要改进 | 限期整改，减少份额，开发替代 |
| D 级 | <60 | 淘汰级，不达标 | 停止新单，存量处理，限期退出 |
**改进方向建议**（按最薄弱维度）：
- 质量分最低 → 加强来料检验，推动供应商改进工艺
- 交付分最低 → 优化订单提前期，增加安全库存
- 服务分最低 → 建立定期沟通机制，明确响应时效
- 价格分最低 → 重新谈判价格，或开发竞争性供应商
### RPN 风险值解读
| RPN 范围 | 风险等级 | 应对策略 | 跟踪频率 |
|---------|---------|---------|---------|
| 80-125 | 🔴 高风险 | 必须制定应急方案，指定风险负责人 | 每月跟踪 |
| 40-79 | 🟡 中风险 | 制定预案，明确触发条件 | 每季度跟踪 |
| 1-39 | 🟢 低风险 | 保持监控，定期评估 | 每半年评估 |
**RPN 三维拆解**：
- 发生概率高 + 影响大 → 立即行动（如开发备选供应商）
- 发生概率高 + 影响小 → 降低概率（如增加质检频次）
- 发生概率低 + 影响大 → 制定应急预案（如购买保险）
- 可检测性高 → 加强监控即可（如安装在线检测）
### TCO 总成本解读
| 成本项 | 典型占比 | 降本优先级 | 说明 |
|--------|---------|-----------|------|
| 采购价格 | 50-65% | ⭐ 最高 | 谈判降本的主要空间 |
| 质量成本 | 5-15% | 高 | 退货、返工、停线的隐性成本 |
| 物流成本 | 3-8% | 中 | 路线优化、整车运输 |
| 库存成本 | 2-5% | 中 | 降低安全库存、提高周转 |
| 应急成本 | 1-5% | 低 | 减少紧急采购频次 |
### ESG 评分解读
| 等级 | 分数 | 含义 | 改进路径 |
|------|------|------|---------|
| A 级 | ≥80 | ESG 领先 | 保持并推广经验 |
| B 级 | 60-79 | 满足基本要求 | 向 A 级看齐，补强短板 |
| C 级 | 40-59 | 需改进 | 制定改进计划，1年内提升至B |
| D 级 | <40 | 重大风险 | 限期整改，否则考虑替换 |
### 谈判达成率解读
| 达成率 | 评价 | 分析方向 |
|--------|------|---------|
| ≥100% | 🏆 超预期 | 总结经验，是否目标设低了？ |
| 80-99% | ✅ 达成 | 正常范围，分析哪些条款做了让步 |
| 50-79% | ⚠️ 基本达成 | 分析差距原因，下次如何改进 |
| <50% | ❌ 未达成 | 复盘准备是否充分，BATNA 是否可行 |

## 进阶使用建议
### 搭建顺序原则
| 原则 | 说明 | 反模式 |
|------|------|--------|
| 先核心后扩展 | 先搭供应商+订单+合同，再搭绩效+降本 | ❌ 一次搭全部 23 类表 |
| 先基础后分析 | 先确保数据录入准确，再搭建分析仪表盘 | ❌ 数据没录完就建仪表盘 |
| 先手动后自动 | 先手动跑通流程，再配置自动化 | ❌ 流程没理清就配自动化 |
| 先单表后关联 | 先确保单表字段正确，再设置表间关联 | ❌ 表还没建好就设关联 |
### 字段精简原则
```
第一轮：核心必填字段（编号+名称+状态+关键日期+关键金额）
第二轮：分类和关联字段（类型+等级+关联其他表）
第三轮：公式和辅助字段（计算字段+预警标记）
第四轮：扩展字段（备注+附件+ESG+合规）
```
> 💡 每张表控制在 15-25 个字段，超过 30 个字段时考虑拆分表。
### 命名规范建议
| 项目 | 规范 | 示例 |

| 订单编号 | PO-YYYYMMDD-XXX | PO-20260815-001 |

| 百分比 | 纯数字 | 95 而非 "95%" |

# 采购多维表格搭建 Skill

版本：v2.1.2 | 作者：liucaiwei

## 这是什么

一个「豆包工作」Skill：安装后，用一句话即可生成覆盖采购全流程的多维表格体系——23张标准表、50+条飞书原生公式、S/A/B/C/D五级供应商分级与卡拉杰克品类策略，开箱即用。

## 核心能力

| 能力 | 说明 |
|---|---|
| 23张表覆盖采购全流程 | 供应商管理、采购执行、财务结算、分析决策四大板块 |
| 50+条飞书原生公式 | 预测偏差率、谈判达成率、降本测算等，不用自己写 |
| S/A/B/C/D五级供应商分级 | 按绩效分数自动评定 |
| 卡拉杰克品类策略矩阵 | 按品类阈值×风险等级自动分入四象限 |
| 风险与库存预警 | HHI供应商集中度、库存周转自动提示 |
| 降本量化追踪 | 每笔订单降本自动累计 |

## 23张表概览

- **供应商管理**：供应商档案、资质证照、绩效评定、分级体系
- **采购执行**：需求申请、采购订单、合同管理、收货验收
- **财务结算**：付款申请、发票管理、降本测算
- **分析决策**：需求预测、谈判管理、库存周转、HHI集中度、卡拉杰克矩阵、风险管理

## 关键公式

```
预测偏差率 = IF(实际需求量 > 0, ABS(预测-实际)/实际×100, 0)
预测准确率 = MAX(0, 100 - 预测偏差率)
谈判达成率 = (底线价-成交价)/(底线价-目标价)×100
```

## 质量保证

所有公式已通过 61 项自动化校验：基线复算、边界测试（除零/负值钳制）、跨文档一致性全部通过。

运行校验：
```bash
bash scripts/test.sh
```

## 安装与使用

1. 下载本目录
2. 在豆包工作中导入 Skill
3. 输入需求，自动生成全套多维表格
